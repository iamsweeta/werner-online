# Как пользоваться · 59.0

## Ежемесячное обновление

При входе сразу доступны ранее сохранённые цены. Повторно загружать документы для просмотра не нужно. Откройте «Прайс-листы», выберите компанию, добавьте новые документы, распознайте и проверьте значения, затем подтвердите сохранение. После этого пересоберите большую Excel-таблицу.

При работе по ссылке данные находятся на сервере. Их сохранность зависит от постоянного каталога данных: инструкция для обновления сервера — в README.md. Закрытие браузера цены не удаляет.

## Ручная цена

В «Одном маршруте» нажмите цену либо пустую ячейку. Укажите число, при необходимости единицу, и нажмите «Сохранить цену». Правка действует только для указанной компании, направления и весового диапазона. На экране и в источниках Excel она помечается «Введено вручную».

Для веса до 50 кг вводите всю стоимость отправки, а не результат деления на вес. Для тяжёлых весов ставка ₽/кг заполняет тарифный столбец большой таблицы; сумма ₽ заполняет сравнение и отдельный Excel маршрута. Итоговая сумма не подтверждает опубликованную ставку за килограмм.

Чтобы отменить правку, откройте ячейку и нажмите «Убрать ручную цену». Применение нового файла заменяет ручные цены только в ячейках, которые этот файл покрывает; онлайн-обновление не стирает правки.

## Файл для конкретного направления

Загрузите и подтвердите документ в «Прайс-листах». Нажмите «Выбрать маршрут из файла» или откройте нужное направление в «Одном маршруте». В блоке «Прайсы для этого маршрута» выберите файл и нажмите «Применить». Увидите подтверждение с названием и количеством цен. Выбор сохранится для обеих выгрузок и следующего входа.

Если документ не предлагается, проверьте компанию и направление: прайс из Москвы не является прайсом обратного маршрута. Дату и значения можно сверить по ссылке на оригинал. При смене редакции примените новый прайс. Старую редакцию можно отключить в библиотеке.

## Диаграмма

По умолчанию доступны все контрольные веса 0–20 тонн. Ползунки «От» и «До» сужают окно; также есть три готовых масштаба. На графике всегда рубли за отправку, переключатель единицы таблицы работает отдельно. Нулевой вес задаёт границу окна; цена отправки нулевого веса не рассчитывается. Неизвестные значения не соединяются выдуманными точками.

## Две выгрузки

«Скачать Excel маршрута» создаёт отдельный файл выбранного направления с листом источников.

«Большая таблица» → «Основные · 254» → «Собрать Excel из сохранённых цен» создаёт общую книгу в формате заказчика. Для получения свежих данных с сайтов нажмите «Обновить цены онлайн». Если остановите сбор, уже полученные цены останутся. Можно пересобрать Excel из доступных данных или продолжить задание через историю.

Пустая ячейка в Excel означает отсутствие подтверждённого значения. Даты и происхождение видны на листе «Источники». Сам скачанный XLSX не обращается к сайтам при открытии — обновление и пересборку запускают в приложении.

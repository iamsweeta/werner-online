# Изменения версии 63.0

Главное изменение — цены и библиотека документов могут храниться отдельно от диска Render. Настройка описана в SETUP_RENDER_NEON.html. Перед обновлением действующего сайта скачайте резервную копию.

- В режиме `TARIFF_STORAGE=cloud` PostgreSQL хранит цены, ручные изменения, выбранные документы, историю обновлений и состояние большой таблицы. Оригиналы и готовые большие Excel сохраняются в закрытом S3-совместимом хранилище. Локальная папка используется как кэш.
- Подтверждение загрузки выдаётся после удалённого сохранения. Ошибка облака не переключает приложение незаметно на пустую локальную базу.
- Добавлена страница `/storage-guide`: проверка подключения, перенос резервной копии, статус переноса и повтор после перезапуска. Данные переносятся только в пустую базу, одной транзакцией. Есть прямой перенос с компьютера для больших архивов.
- Сохраняются файл и состояние предпросмотра. Прерванное распознавание можно повторить из принятого документа в пределах срока предпросмотра. Скан распознаётся заново; сохранённые подтверждённые цены не теряются.
- Повторное «Применить цены из файла» возвращает подтверждение уже выполненного действия и не создаёт дубликат или новую ревизию.
- Добавлены локальный помощник настройки Neon, пример переменных и конфигурация Render Free. В облачном режиме обязателен пароль сайта; секреты не входят в архив и резервные копии.
- Сохранены локальная SQLite, отдельный Excel маршрута, большая таблица, ручные ячейки, переключение единиц, светлая и тёмная темы.

Шаблон Excel не изменялся в этой версии. Рабочие цены в дистрибутив не добавлялись. Для онлайн-цен по-прежнему нужны доступные официальные источники перевозчиков; облачное хранение не обходит их ограничения.

Обновления кода недостаточно для переноса: нужно создать внешнее хранилище, добавить переменные Render и загрузить прежнюю резервную копию. Удалённые ранее данные без копии восстановить невозможно.

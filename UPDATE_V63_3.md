# Обновление до 63.3

Версия добавляет использование одного сохранённого прайса для разных направлений,
прямой онлайн-расчёт Байкала и обновлённый интерфейс. Существующие цены и файлы
остаются в вашей базе. Создавать новый проект Neon или бакет не нужно.

## Как установить на ваш Render

1. На действующем сайте откройте «Прайс-листы» → «Хранилище и резервная копия»
   и скачайте резервную копию, если там уже есть важные данные.
2. Распакуйте `tariff_app_63_3.zip`. Загрузите **содержимое** папки
   `TARIFF_APP_V63_3` в ваш репозиторий GitHub с заменой файлов.
   Папки `app`, `static`, `data` и файл `requirements.txt` должны быть в корне
   репозитория, а не внутри дополнительной папки `TARIFF_APP_V63_3`.
   В частности, должны попасть новые `app/baikal.py` и `static/refinements.css`.
3. В Render → ваш сервис → Environment сохраните существующие `DATABASE_URL`
   и все `S3_…`. Для общего сайта с сохранением в облаке оставьте:

   ```env
   TARIFF_STORAGE=cloud
   APP_AUTH_MODE=public
   ```

   Не загружайте `render.env`, пользовательские прайсы или пароли в GitHub.
4. В Render выберите **Manual Deploy → Deploy latest commit**. Дождитесь Live
   именно для нового коммита. Если меняли переменные — Save, rebuild, and deploy.
5. Откройте `/health` на вашем сайте. Ожидается:

   ```json
   {"version":"63.3","access_mode":"public","storage_mode":"cloud"}
   ```

6. Обновите главную страницу через Ctrl+F5. На телефоне закройте старую вкладку
   и откройте сайт снова. Цены из прежней базы должны появиться без онлайн-сбора.
7. На `/storage-guide` можно проверить подключение. Повторно запускать настройку
   Neon и переносить резервную копию в уже заполненную базу не нужно.

Этот архив не устанавливает обновление на Render автоматически.

## Один документ — несколько маршрутов

1. В «Одном маршруте» выберите города, например Москва → Санкт-Петербург.
2. Нажмите **«Цены из файла»** и выберите компанию.
3. Если файл уже загружен и подтверждён, откройте **«Из библиотеки»** и выберите
   его. Подходят сохранённые файлы из обоих разделов, включая старые загрузки.
4. Если цены этого направления уже подтверждены, кнопка будет называться
   **«Применить сохранённые цены»** — повторного распознавания не будет.
5. Если направление ещё не извлекалось, нажмите **«Извлечь цены для маршрута»**.
   Приложение прочитает оригинал на сервере. Проверьте результат, поставьте
   отметку проверки и нажмите **«Применить цены из файла»**.
6. Появится подтверждение с числом применённых цен. Они используются в таблице,
   диаграмме, отдельном Excel маршрута и при следующей сборке большой таблицы.
7. Выберите другой маршрут и тот же файл в библиотеке. Повторно отправлять его
   с компьютера не требуется. В библиотеке останется один оригинал, а число
   распознанных направлений увеличится.

Для нового документа выберите «Новый файл». Он останется в библиотеке после
применения. Если нужно сразу распознать все направления документа, используйте
раздел «Прайс-листы»: несколько файлов компании можно загружать вместе.

Если направления в документе нет, приложение объяснит ошибку. Цены другого города
не подставляются, обратное направление автоматически не рассчитывается.
Распознавание нового направления из скана может занять время. Уже подтверждённое
направление повторного OCR не требует. Поддержка макетов PDF/OCR остаётся прежней:
произвольный скан любого перевозчика не гарантирован; доступен XLSX/CSV-шаблон.

## Байкал Сервис

В «Одном маршруте» включите Байкал среди компаний и нажмите «Обновить онлайн».
Теперь используется публичный калькулятор `https://request.baikalsr.ru/calculator/`
через HTTPS. API-ключ и Chrome на Render не нужны. Для каждого контрольного веса
запрашивается отдельный расчёт; города и терминалы определяются по текущему
справочнику перевозчика. То же подключение используется в большой загрузке.

База сравнения: межтерминальная автоперевозка с плотностью 200 кг/м³,
без адресной доставки, упаковки, страхования, информирования и платы за въезд.
Топливный сбор, включённый перевозчиком в стоимость межтерминальной услуги,
повторно не прибавляется. Это предварительный расчёт перевозчика по указанным
параметрам, а не индивидуальное коммерческое предложение для любого груза.

При проверке 30.09.2026 UTC Москва → Санкт-Петербург вернулись 27 из 28 весов.
Для 20 т при объёме 100 м³ официальный калькулятор сообщил предел 72 м³.
Приложение не уменьшает объём ради получения другой цены и не заполняет пропуск
догадкой. Для этого веса можно применить подтверждённый тарифный файл.
Проверены также обратный маршрут и Москва → Казань. Доступность всех направлений
сразу не гарантирована; при отказе источника сохраняются прежние цены с их датой.

Калькулятор возвращает **сумму отправки**, не опубликованную ставку ₽/кг.
На экране и в отдельном Excel можно выбрать расчётное ₽/кг = сумма / вес.
В **большом Excel по эталону** тяжёлые колонки требуют ставки из прайса:
если есть только сумма калькулятора, такая ячейка остаётся пустой, а сумма и
источник видны в листе источников. Для заполнения этих колонок нужен документ
со ставками. Форма исходного Excel и правило пустых ячеек не изменены.

## Интерфейс

- «Один маршрут» остаётся первым экраном. Основные действия — онлайн-обновление,
  цены из файла и отдельный Excel маршрута.
- На телефоне навигация перенесена вниз. Выбор городов, единиц и кнопки компактнее.
- Мобильная таблица по умолчанию показывает выбранную компанию без широкой
  горизонтальной прокрутки. Компания переключается списком; кнопка «Все компании»
  открывает полное сравнение. Ручное редактирование ячейки сохраняется в обоих видах.
- Легенда диаграммы и дополнительные пояснения свёрнуты. Все точки графика
  сохраняются; единицы ₽ и ₽/кг и ползунки диапазона остаются доступны.
- Светлая тема имеет белый фон, тёмная — тёмные поверхности и контрастный текст.

## Что хранится

Подтверждённые оригиналы, цены и выбор источника не имеют срока автоматического
удаления в приложении. В облачном режиме цены и связи хранятся в PostgreSQL,
оригиналы — в S3. База и бакет должны оставаться доступны и укладываться в лимиты
тарифа провайдера. Render может перезапускаться без удаления этих данных.
Временный неподтверждённый предпросмотр действует 30 минут; это не срок хранения
подтверждённого прайса. Метка LIVE также действует 30 минут, но сама цена сохраняется.

Большую таблицу после изменения цен нужно **создать заново из сохранённых данных**.
Уже скачанный Excel самостоятельно через интернет не обновляется.

# Проверки 59.0

Проверен код и локальная сборка приложения. Установку на сервер заказчика эта проверка не заменяет.

## Новые сценарии

- POST/DELETE ручной цены: отдельные компания, направление и вес; сумма/ставка; дробная запятая; отклонение формул, NaN, Infinity, отрицательных значений и неподходящей единицы.
- Ручная цена сохраняется после запуска нового процесса, попадает в отдельный Excel маршрута и в соответствующий тарифный столбец большой книги. Удаление возвращает доступный исходный источник.
- Применение файла возвращает имя, число значений, компанию и направление; покрытые ручные ячейки заменяются, непокрытые остаются.
- Подтверждённый прайс с метаданными 65-дневной давности доступен сразу. Онлайн-цена 45-дневной давности остаётся при ошибке обновления; статус не становится LIVE.
- Переход через полночь Москвы проверен независимо от часового пояса сервера; действительно будущая дата отклоняется.
- Реальный официальный генератор Возовоза: Москва → Санкт-Петербург и Санкт-Петербург → Москва, по 29 профилей. Ошибка отклонения текущего прайса из-за даты сервера устранена. Проверка не является гарантией будущей доступности сайта или всех направлений.
- Диаграмма: диапазон 0–20 т по умолчанию, сужение границ, обработка их пересечения, сохранение рублей за отправку на оси графика при переключении единиц таблицы.
- UI ручной ячейки: корректное исходное значение/единица, сохранение, удаление, подтверждение успеха; ошибка сети сохраняет черновик и оставляет окно открытым.
- UI выбора документа: видимое подтверждение с именем файла и числом цен; повторный вход восстанавливает выбранный источник.
- Остановка: после сигнала новые компании не запускаются, уже запущенные проверки завершаются и сохраняются.

## Большая книга и прежние функции

Проверена отдельная полная выгрузка **254 маршрутов × 17 компаний**. Задание остановлено до первой новой проверки; книга получила онлайн-значения из прошлой загрузки, файл обратного направления и ручную ставку. Все 254 направления присутствуют. Пустые тарифы остаются пустыми. Смена ручной цены делает ранее готовый файл устаревшим и требует пересборки. Для этого сценария использованы явно помеченные тестовые данные, которые не входят в рабочую базу архива.

Выполнены 215 сценариев существующего и нового backend-набора. Два теста обновлены под новый аргумент остановки загрузчика и правильную маркировку сохранённого отчёта, после чего оба повторно прошли. Дополнительно пройдены 5 проверок OCR-кэша/контуров и тест остановки. Выполнены сценарии UI через JSDOM, включая новую ручную ячейку, документы, графики, темы, импорт, паузу и отдельную выгрузку.

Проверки экспорта подтверждают структуру эталона, единицы фиксированных сумм/ставок, отдельный файл маршрута, отсутствие цен/формул в очищенном шаблоне и отсутствие готовых рабочих цен в чистой установке.

## OCR

Реальный ранее приложенный девятистраничный PDF ДЛ: распознаны 220 строк направлений из межтерминального раздела. Все 20 исходных чисел каждой строки совпали с ранее проверенным результатом обычного OCR; ошибок строк нет. Из них 3780 ячеек прочитаны по контурам символов, подтверждённым на этом документе; остальные — обычным OCR. Полный прогон занял около 86 секунд при одновременном выполнении тестов, повторное чтение кэша — около 0,01 секунды. Это замер данного файла и среды, а не обещание времени обработки любых документов.

Растровый PDF проверен встроенным OCR без системной команды tesseract. Кэш учитывает точное содержимое, компанию, область распознавания и версию парсера; ошибки не кэшируются. Лимиты — 7 дней, 64 результата, 32 МБ. Частичное распознавание одного маршрута не заменяет полный индекс документа. Кэш не применяет цены без подтверждения.

## Ограничения

- В браузере заказчика и на реальном мобильном устройстве визуальная проверка не выполнялась; проверены DOM-сценарии и адаптивные CSS-правила. Светлая и тёмная темы сохранены.
- Достоверность ручного ввода зависит от пользователя; он не выдаётся за онлайн-проверку. OCR требует сверки с оригиналом.
- Неподдерживаемые макеты, неопубликованные ставки, защита сайтов и отсутствие API-доступа оставляют пустые ячейки/понятную ошибку; готовые цены не подставляются.
- Бессрочное хранение требует сохранности серверного каталога данных. Временный диск хостинга или удаление runtime не компенсируются кодом приложения.
- XLSX — снимок данных на момент сборки; он не обновляет себя из интернета при открытии.

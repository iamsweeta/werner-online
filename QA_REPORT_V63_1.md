# Проверка версии 63.1 — 29 сентября 2026

## Подтверждённая диагностика

Во время проверки действующий сайт версии 63.0 вернул HTTP 401 для главной страницы
и `/api/options` при запросе без авторизации. Это подтверждает включение парольного
режима, но не проверяет состояние базы под учётной записью пользователя.
В ходе работы настройки живого сайта, Neon и пользовательские данные не изменялись.

## Проверки новой версии

- 4 теста режима доступа: явное включение public, работа со старым APP_PASSWORD,
  защищённый режим, отклонение ошибочного значения конфигурации, доступ к HTML,
  JavaScript и справочнику, отказ при неверном пароле, проверка Origin запросов.
- 31 основной тест API/расчётов/выгрузки: пройден. Версия в Excel обновлена до 63.1.
- 7 тестов помощника настройки Neon: пройдены. Проверяются выбор проекта и ветки,
  обработка ошибок API, создание закрытого бакета, защита существующего render.env.
- 8 интеграционных тестов PostgreSQL и S3: пройдены. Включают публичный режим без
  APP_PASSWORD, сохранение ручной цены, библиотеку, оригиналы, Excel, перенос резервной
  копии, восстановление после очистки локального runtime и запуска нового процесса.
  PostgreSQL проверен через локальный PGlite; файловое хранилище — через Moto S3.
  Это не проверка соединения с конкретным проектом Neon пользователя.
- 16 файлов тестов интерфейса JSDOM: все пройдены. Новые сценарии проверяют старт
  после 401/503, видимое сообщение, повторную загрузку городов/компаний/большой таблицы,
  независимость справочника от чтения цен, различение тайм-аута и отмены смены маршрута.

## Границы изменений

Парсеры, формулы цен, правила выбора документов и структура Excel не изменены.
Рабочие цены не добавлялись. Тестовые данные находятся только в тестах и не
используются приложением для заполнения таблиц. Новая проверка актуальности цен
на сайтах всех перевозчиков в эту работу не входила.

После развёртывания на Render необходимо проверить `/health` и выполнить проверку
PostgreSQL/S3 на `/storage-guide`: без доступа к настройкам сервиса эту проверку
конкретного облачного хранилища нельзя подтвердить заранее.

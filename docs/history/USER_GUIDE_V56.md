# 56.0 · Быстрое распознавание выбранного маршрута

## Обновление

1. Закройте прежнее приложение. Распакуйте архив в новую папку.
2. До запуска перенесите папку `runtime` из старой установки, чтобы сохранить подтверждённые прайсы и последние цены. При использовании `TARIFF_DATA_DIR` оставьте прежний постоянный каталог.
3. В Windows запустите `START_WINDOWS.cmd`. Для Linux/macOS: установите `requirements.txt`, затем запустите `python launch.py`.
4. Если приложение открывается по ссылке на хостинге, нужно обновить именно запущенное приложение на сервере и перезапустить его. Затем обновите страницу браузера. Скачивание архива само по себе опубликованную версию не меняет.

## Один маршрут

1. Выберите направление, откройте загрузку прайса, укажите компанию и документ.
2. Нажмите «Распознать». Сервер примет файл и запустит фоновое задание. Приложение ищет выбранный город и читает только его строку. Показываются страница, этап и прошедшее время. Для полной обработки всех маршрутов используйте «Прайс-листы».
3. Можно закрыть окно или перезагрузить страницу. Откройте загрузку прайса для того же направления в том же браузере: приложение подключится к заданию и покажет готовый предпросмотр. Сохранение номера задания требует доступного локального хранилища браузера.
4. При временной 502/503/504 приложение повторяет запрос статуса, а не загрузку документа. Если связь не восстановилась, повторно откройте окно или нажмите распознавание — сначала будет проверено уже запущенное задание.
5. Сверьте цены и подтвердите применение. До подтверждения цены в библиотеке и Excel не меняются. Готовый предпросмотр действует 30 минут.

Если сервер полностью перезапустился во время OCR, задача не может продолжить вычисления: примерно через 90 секунд она будет отмечена прерванной с пояснением. Загрузите файл заново. Уже подтверждённые прайсы остаются на диске. Автоматического применения незавершённых заданий нет.

## Ваш PDF ДЛ

Для `dsjf.pdf` город отправления — **Санкт-Петербург**, дата прайса — **03.08.2026**. Для направления из Москвы нужен московский файл. Апостроф после `.pdf` исправляется автоматически. Сканы межтерминальных таблиц ДЛ распознаются локально, включая повёрнутые страницы; для другого сканированного макета используйте XLSX-шаблон.

Через «Один маршрут» сохраняется выбранное направление. Для всех распознанных направлений документа загружайте его через общую библиотеку **«Прайс-листы»**, выбрав **ДЛ → Определить из файла**. Подтверждённые документы доступны и сравнению, и большой таблице. После изменения прайсов пересоберите большой Excel; отдельный маршрут скачивается отдельным файлом.

Модели OCR уже в архиве, внешний Tesseract и облачный OCR не нужны. Загрузки хранятся бессрочно, пока вы сохраняете папку данных. Числа OCR требуют проверки по оригиналу; дата загрузки не заменяет дату тарифов, загруженный документ не помечается LIVE.

## Если раньше оставалось «Страница 1 из 9»

Версия 55.0 читала цены всех городов даже для одного направления и сообщала прогресс только при переходе страницы. Версия 56.0 сокращает эту работу. После замены файлов перезапустите сервер; старое незавершённое задание нужно загрузить заново. Если страница продолжает показывать старое сообщение без названия этапа, убедитесь, что в диагностике версия 56.0, и обновите страницу с очисткой кэша.

Через 30 секунд на одном этапе появится пояснение о долгом выполнении. Через 120 секунд без завершения этапа отдельный OCR-процесс будет остановлен; цены не применяются, показывается ошибка. Переход между этапами, а не пульс сервера, сбрасывает этот таймер. На слабом/перегруженном сервере может понадобиться текстовый PDF или XLSX либо увеличение ресурсов сервера. Закрытие окна не останавливает серверное задание; перезапуск сервера его прерывает. Общий предел OCR — 10 минут.

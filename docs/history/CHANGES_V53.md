# Версия 53.0

- Устранено разделение загрузок: одиночный импорт сохраняется в той же SQLite-библиотеке, что и многостраничные/многомаршрутные документы.
- Старые JSON-загрузки одного маршрута автоматически регистрируются в библиотеке без потери оригинала и без повторного включения отключённых файлов.
- Добавлен серверный выбор документа для пары компания + отправление + назначение. Он сохраняется после перезапуска и учитывается в сравнении, графиках и обеих Excel-выгрузках.
- Подтверждённая загрузка выбирается для её распознанных направлений. Выбранный файл имеет приоритет над онлайн-ценами для содержащихся в нём весов. Предусмотрен возврат к автоматическому выбору источника.
- В «Одном маршруте» появился список подходящих файлов. В библиотеке можно просмотреть направления файла и сразу открыть нужное в сравнении.
- Изменение выбора помечает готовую большую выгрузку как требующую пересборки. Компания, направление, исходный файл и дата не подменяются.
- Сохранены три масштаба графика, ручное онлайн-обновление, сохранённые цены, две темы, исправление PDF с апострофом и пустые ячейки Excel при отсутствии подтверждённой ставки.

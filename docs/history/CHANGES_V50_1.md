# Версия 50.1

- Белый фон светлой темы. Тема применяется до отрисовки страницы; прежний автоматический выбор тёмной темы сброшен один раз. Явный выбор сохраняется.
- Удалена подпись внизу боковой панели и номер версии из этой подписи.
- «Скачать Excel маршрута» скачивает самостоятельный XLSX с именем маршрута: таблица выбранных компаний и лист источников. Общая книга выгружается отдельно. Режим ₽/₽ за кг соответствует экрану; МИН всегда ₽.
- Возовоз: ошибка скачивания дополнительного файла больше не отменяет успешно разобранный прайс обычной перевозки; одинаковые повторные файлы разрешены, конфликтующие цены отклоняются.
- Для генератора Возовоза добавлен второй TLS-клиент при технической ошибке соединения. Проверка сертификатов остаётся включённой. Отказы в доступе не обходятся.
- Цены из предыдущих загрузок не включены в поставку. Онлайн-сбор и ручная загрузка прайсов сохранены.

Подробности проверки и ограничение живой проверки Возовоза: QA_REPORT_V50_1.md.

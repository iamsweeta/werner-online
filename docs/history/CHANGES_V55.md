# 55.0 · Ошибка 502 при распознавании в «Одном маршруте»

Подтверждённый дефект 54.0: интерфейс держал один запрос `/api/import/preview` открытым на всё время OCR (для пользовательского PDF — несколько минут). Увеличение тайм-аута в браузере не меняло ограничения прокси или хостинга. Журналы хостинга пользователя не предоставлены, поэтому непосредственная причина именно его ответа 502 не утверждается как установленная.

Исправления:

- Интерфейс создаёт задание через `POST /api/import/jobs` и сразу получает HTTP 202. OCR больше не удерживает этот запрос.
- Готовность и прогресс читаются короткими GET-запросами. 502/503/504 и временные сетевые сбои запускают повторное чтение статуса без нового OCR.
- Номер задания хранится в браузере. После обновления страницы повторное открытие диалога того же направления восстанавливает готовый предпросмотр/наблюдение.
- Идемпотентный идентификатор защищает от повторного запуска при повторе POST; другой файл/маршрут с тем же номером отклоняется.
- Статусы хранятся в SQLite и видны другим веб-процессам с общим каталогом данных. Проверяются срок предпросмотра и сигнал работоспособности процесса; перезапуск/обрыв вычисления показывается отдельной ошибкой.
- Цены применяются только после подтверждения. Сохранены общая библиотека, исходные PDF, OCR, обе выгрузки и прежние парсеры.

Старый синхронный API оставлен для совместимости, но интерфейс 55.0 его больше не использует. Для применения исправления требуется обновить работающий сервер/приложение и страницу браузера.

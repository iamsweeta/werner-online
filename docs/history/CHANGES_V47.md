# v47.0 — общий онлайн-сбор и Excel по всем компаниям

## Получить общий Excel

1. Запустите приложение и откройте **«Все компании и маршруты»**.
2. По умолчанию выбран режим **«Все маршруты из Excel-образца»**: 318 направлений, 18 компаний, 5 724 проверки компаний. В список перенесены только пары городов. Цены из образца не используются.
3. Нажмите **«Обновить все и подготовить Excel»**. Сбор запускается независимо от выбранных компаний, маршрута и фильтров в верхней части страницы.
4. Следите за прогрессом. После проверки всех направлений файл создаётся автоматически. Нажмите **«Скачать общий Excel»**.
5. Для обновления цен запустите новый общий сбор той же кнопкой. Он повторно проверит источники и создаст новый отчёт.

Завершение проверки означает получение результата для каждой пары «компания — маршрут». Это не обещание числового тарифа во всех ячейках: компания может не публиковать такой маршрут, выдавать индивидуальный расчёт или ограничивать доступ к сайту. Причины видны в приложении и на листе «Источники».

## Другие списки направлений

- **Из выбранных городов.** Выберите один или несколько городов отправления. Пустой выбор назначения означает все города справочника. Можно выбрать конкретные города назначения. В Windows несколько пунктов выбираются с Ctrl / Shift.
- **Все пары городов справочника.** 233 города, 54 056 направлений и 973 008 проверок компаний. Обратное направление — отдельная проверка. Это все возможные пары справочника, а не подтверждённая сеть каждого перевозчика.

В справочник добавлены Минск и Гомель из образца. Склеенные написания вроде «НижнийНовгород» сопоставляются с однозначным названием города. Строки «город» / «Все города» не считаются маршрутами.

Программа показывает размер выбранного сбора до запуска. Полный перебор большого справочника может занимать дни и более. Сайты проверяются с ограниченным числом параллельных запросов. Не нужно запускать несколько копий программы.

## Пауза, продолжение и ошибки

Кнопка **«Пауза»** завершает проверки текущего маршрута и останавливает переход к следующему. Уже полученные ответы сохраняются после каждой компании. Закрытие вкладки браузера не останавливает сбор, пока работает окно приложения.

После остановки или перезапуска приложения последний незавершённый сбор отображается с кнопкой **«Продолжить»**. Повторно запрашиваются только незавершённые компании. Это продолжение прежнего отчёта: даты ранее полученных строк не обновляются искусственно.

**«Повторить ошибки и неполные таблицы»** повторно запрашивает соответствующие компании. Полные таблицы сохраняются. Неполные таблицы могут снова остаться неполными, если перевозчик не публикует часть весов. Неподдерживаемые маршруты автоматически повторно не опрашиваются.

На паузе или после ошибки можно подготовить частичный Excel по уже проверенным маршрутам. Лист «Сбор» показывает план и выполненный объём. Общий сбор и обычное обновление одной пары не запускаются одновременно. Просматривать сравнение других маршрутов можно во время сбора.

## Полная весовая сетка

Для каждой компании запрашиваются доступные 28 контрольных весов и определяется МИН. Документные источники читают таблицы тарифов; калькуляторы запрашивают веса отдельно. В общем режиме расширены региональный Proline и точные калькуляторы ДЛ, Возовоза и Байкал Сервиса. Сетевые ошибки отдельных весов не заменяются рассчитанными по соседнему весу ценами.

Если официальный источник даёт только цену «от», она не размножается по всем весам. Числа, которых источник не подтвердил, не достраиваются. Наличие загрузчика компании не означает поддержку им любой пары городов: ограничения прежних адаптеров по направлениям сохранены и показываются как отсутствие подключённого публичного тарифа.

## Что находится в Excel

Сохранена структура образца: отдельные листы компаний, строки маршрутов, МИН, сравнение и графики. Листы «Источники» и «Сбор» содержат даты, происхождение, ошибки и объём выполненной проверки. Смените B16 и F16 на листе «Графики», чтобы сравнить другую пару из листа «Направления».

Единицы прежние: D:L — отправка в рублях; M — минимум в рублях; N:AF — эффективные рубли за кг, то есть цена отправки / контрольный вес. Объёмные тарифы AH:BK пока не собираются. Дополнительные компании и исторические листы из структуры образца не получают вымышленных данных: общий онлайн-сбор включает 18 подключённых компаний приложения.

Общий Excel включает только ответы конкретного онлайн-сбора. Старые значения из исходного архива, предыдущих неуспешных попыток и документы пользователя не подставляются. Обычный **«Excel по образцу»** по-прежнему позволяет экспортировать сохранённые маршруты с выбранными фильтрами и импортами.

Большой сбор выполняется последовательно. Ранние ответы могут быть старше 30 минут к моменту завершения. В общем Excel они обозначены **«Проверено при сборе»** с фактическим временем получения. В приложении статус LIVE по-прежнему действует только 30 минут. Сохранённый XLSX сам не опрашивает сайты и не обновляется при открытии: новый сетевой сбор запускается в приложении.

До 400 маршрутов помещаются в один Excel. Более крупный отчёт автоматически делится по 200 маршрутов: ZIP содержит Excel-файлы одинаковой структуры, `routes.csv` с указанием файла для каждого направления и `collection.json` с итогами. Так каждый файл остаётся пригодным для открытия и не превышает лимит строк Excel. Пустые диапазоны одного источника объединяются в аудите; числовые значения остаются на листах компаний.

## Хранение и перенос

Очередь, ответы и готовые выгрузки находятся в `runtime/bulk/`. Для переноса прогресса закройте приложение и скопируйте **всю папку `runtime`**, включая файлы SQLite, в новую установку. Нельзя копировать открытую базу во время записи. Личные документы и настройки сохраняются прежним способом.

В архиве нет пользовательских API-ключей, рабочего кеша и незавершённых задач. Пример `EXAMPLE_ALL_COMPANIES_V47.xlsx` — результат отдельной проверки Москва → Санкт-Петербург с реальными ответами и явными пропусками. Для текущих цен выполните новый сбор.

## API

- `POST /api/bulk/plan` — предварительный размер. Тело: `{"scope":"reference"}`, `{"scope":"all"}` либо `{"scope":"origins","origins":["Казань"],"destinations":["Уфа","Омск"]}`.
- `POST /api/bulk` — тот же запрос, запуск проверки всех 18 компаний.
- `GET /api/bulk` — последний сбор; `GET /api/bulk/{job_id}` — состояние конкретного сбора.
- `POST /api/bulk/{job_id}/pause`, `/resume`, `/retry`, `/export` — управление.
- `GET /api/bulk/{job_id}/download` — готовый XLSX или ZIP.

Файл создаётся в фоне. Результат HTTP 200 при запуске не означает завершение сбора: необходимо дождаться `export_status="ready"`. Ошибки сайта и отсутствие тарифа возвращаются в состоянии компании. `status="done"` означает, что все запланированные проверки выполнены.

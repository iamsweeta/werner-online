# Изменения v48.0

- Большая таблица стала основным разделом. Отдельные вкладки для маршрута и прайс-листов.
- Общий отчёт по всем 18 подключённым компаниям использует подтверждённые документы для отсутствующих точных онлайн-цен.
- Добавлен режим формирования отчёта без запросов к сайтам.
- Можно выбрать несколько документов одной компании: объединяются маршруты и непересекающиеся веса; конфликтующие цены требуют явного выбора версии.
- Предпросмотр показывает маршруты, суммы с копейками, имена исходных файлов, страницы/строки и дату. Сохранение — после подтверждения клиента.
- Оригиналы документов, привязки и выбор цен сохраняются. Новая версия прайса не оставляет отсутствующие веса из прежней версии.
- Добавлены CSV и пустой многомаршрутный XLSX-шаблон с подготовленными маршрутами и весами.
- После изменения документов готовый Excel требует пересборки; прежняя ссылка на скачивание блокируется.
- После формирования отчёта показано заполнение по компаниям: онлайн, файлы, пропуски; из каждой строки можно перейти к загрузке прайса этой компании.
- Экспорт выбранного маршрута по умолчанию включает только этот маршрут. Общая выгрузка не зависит от фильтров сравнения.
- Сохранены онлайн-загрузчики, отдельный импорт маршрута, минимумы, графики, пауза и продолжение общего сбора, повтор ошибок, API-настройки.
- Обновлены светлая и тёмная темы, навигация с клавиатуры, мобильные формы, карточки сравнения и прокрутка широких таблиц.

Подробный порядок действий и ограничения форматов — в README.md. Программа обновляет только подтверждённые цены: полного набора чисел при отсутствии исходных данных она не создаёт.

# 54.0 · OCR сканов ДЛ

- Исправлен отказ загрузки PDF без текстового слоя для межтерминальных прайсов ДЛ.
- Автоматически распознаются повёрнутые на 90/180/270 градусов страницы; русский заголовок подтверждает город отправления.
- Структура таблицы проверяется по диапазонам, минимуму и единице руб/кг. Цены извлекаются из фактических ячеек; тарифных констант и подстановок нет.
- Два чтения чисел; при расхождении — дополнительные чтения отдельных ячеек. Пропущенная запятая не восстанавливается по величине числа. Неоднозначные строки исключаются с объяснением.
- OCR вызывается один раз на документ в сеансе, затем результат используется для всех направлений. Обработка вынесена в отдельный процесс с ограничениями времени и размера; одновременно до двух OCR-заданий.
- Работают общая библиотека, импорт одного направления, выбор файла, оба Excel-отчёта и сохранение оригинала. Источник помечен OCR; сохранены дата прайса и страницы.
- В интерфейсе показан ход OCR и обновлены подсказки. Модели включены в архив. Текстовые PDF используют прежние парсеры.

Сканы произвольных макетов других компаний в этой версии автоматически не разбираются. Описание поддерживаемых форматов и порядок загрузки — USER_GUIDE_V54.md.

## Практические ограничения

- XLSX — снимок сбора, не автоматически обновляемая при открытии Excel книга. Для новых цен запускается новое онлайн-обновление; пересборка добавляет подтверждённые документы к сохранённому сбору.
- Наличие города в справочнике не подтверждает тариф у каждого перевозчика. Недоступность, «по запросу» и отсутствие ставки видны явно.
- Произвольные макеты и сканы без текстового слоя не распознаются автоматически. Универсальный шаблон диапазонов работает для всех 17 компаний.
- Весовой тариф не включает все возможные объёмные, адресные, страховые и другие услуги. Объёмные колонки эталона сохраняют структуру с отметкой «не собрано».

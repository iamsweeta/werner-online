# v46.0 — МИН и Excel по образцу

## Минимальная стоимость

МИН — минимальная доступная стоимость отправки компании на выбранном маршруте. Учитываются загруженные итоговые суммы и отдельный опубликованный минимум. Сначала используются подтверждённые файлы пользователя, затем текущие LIVE-цены, затем LAST GOOD. Старый дешёвый тариф не уменьшает свежий минимум. Если загружена только одна цена, это минимум среди доступных строк, а не минимальная цена всех услуг перевозчика. Источник сохраняется. МИН всегда в рублях, включая режим ₽/кг.

## Исправления загрузчиков

Proline Москва ↔ Санкт-Петербург: малые веса теперь запрашиваются у официального калькулятора, веса от 100 кг читаются из таблицы направления. Проверены все 29 строк сравнения, включая МИН. МИН — 550 ₽ в обе стороны. Для региональных страниц сохранён расчёт выбранного веса из предыдущей версии; произвольные пары городов не подменяются тарифом Москвы.

Новая Линия: последняя открытая ступень сохраняется, если напечатана в PDF. Пропущенные веса проверяются официальным калькулятором. Для Москвы ↔ Петербурга 10 и 20 тонн возвращают индивидуальный расчёт: в интерфейсе и Excel стоит «по запросу». Подтверждённых чисел для этих весов источник не предоставил. Ставка до 5 тонн не распространяется на 20 тонн. МИН при проверке — 600 ₽ в обе стороны.

## Как получить Excel

После обновления цен нажмите «Excel по образцу». В файле сохранена структура 41 листа образца, добавлены «Байкал Сервис» и «Источники». Цены, старые тарифы и коэффициенты из присланного образца не используются.

На листах компаний:

- A — номер направления; B — откуда; C — куда.
- D:L — стоимость малого отправления, ₽.
- M — МИН, ₽.
- N:AF — эффективная стоимость, ₽/кг: итоговая сумма из приложения / контрольный вес.
- AH:BK — структура объёмных диапазонов. Объёмные тарифы приложением не собираются и обозначены «не собрано».

Сначала идёт выбранный маршрут, затем другие сохранённые направления. Экспорт использует выбранные компании и фильтр источников приложения. Скрытый сбор всех городов не запускается. Отсутствующие данные обозначены текстом, нули или вымышленные цены не подставляются.

На листе «Графики» находятся сравнение и две диаграммы по весу. Измените B16 и F16 на пару из листа «Направления», чтобы просмотреть другой выгруженный маршрут: формулы пересчитают сравнение. В файле сохранены также вычисленные значения для просмотрщиков без пересчёта. «Источники» содержит происхождение, даты, расчёт и ошибки. Исторические разделы Werner оставлены без цен: история тарифов автоматически не собирается.

Переключатель ₽ / ₽/кг в приложении не меняет смешанные единицы этого шаблона. Прежний простой экспорт доступен через API с `layout=matrix`; `all_loaded=false` выгружает только выбранную пару.

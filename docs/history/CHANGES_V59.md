# Изменения 59.0

- Редактирование отдельной ячейки одного маршрута; серверное сохранение, выбор единицы, удаление ручной правки, явное происхождение цены, обе выгрузки Excel.
- Ручные цены включены в резервную копию прайсов. Применение документа заменяет только покрываемые им ручные значения.
- Диаграмма по умолчанию с двумя границами 0–20 т; единая ось стоимости отправки в ₽, сохранены три масштаба.
- Возовоз: проверка даты документа по московскому календарю, независимо от часового пояса сервера.
- Видимое подтверждение применения документа с названием, компанией, направлением и количеством значений; выбранный файл виден после повторного входа.
- Последние цены загружаются из общей базы без сетевого обновления. Подтверждённые документы, онлайн-история и ручные цены не удаляются по давности.
- Общая выгрузка включает весь выбранный список маршрутов и данные прежних запусков, даже если текущий сбор был остановлен до первой проверки. Смена источников/цен требует пересборки старого Excel.
- Сохранены история сборов, остановка запуска следующих компаний, продолжение, упрощённые основные действия и отдельный Excel маршрута.
- Сохранено ускорение OCR: проверка наличия текстовых шрифтов, повторные заголовки, сверка контуров с подтверждёнными символами документа, ограниченный кэш распознавания. При неоднозначности — обычный OCR и проверка пользователем.
- Рабочие цены, пользовательские документы, runtime и результаты тестовых запросов в архив не включены. Каталоги городов и весовые диапазоны — структура приложения, а не цены.

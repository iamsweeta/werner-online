# Проверка v44.0

- 97 автоматических тестов Python: маршруты, цены, свежесть, источники, экспорт и обработка ошибок.
- Проверка интерфейса в jsdom: выбор региональных городов, автоматическая загрузка, сохранение назначения при обновлении прогресса, разворот маршрута, повтор одной компании, фильтры и восстановление фоновой загрузки.
- Четыре полных сетевых проверки по 17 компаниям и дополнительные проверки трёх направлений. Последние результаты после исправлений: LIVE_VERIFICATION.md/json.
- Проверена изоляция кеша: новые направления начинают без цен, обратное направление не наследует прямую цену; несовпадение города в источнике отклоняется.
- Проверено отклонение одинаковой суммы API для всей тяжёлой весовой сетки, прочерков в БСК и неподтверждённого направления в Пролайн.
- Проверены источник КИТ с терминалом вне административной границы города и соответствие его адреса текущей официальной странице.
- Проверка выполнена в Linux. Исполнение Windows-лаунчера на Windows в этой среде не проверялось; сам лаунчер и зависимости сохранены в архиве.

Интернет-источники могут менять доступность, формат и тарифы. Прохождение тестов не доказывает наличие опубликованного прайса для каждой из всех возможных пар городов.

# Проверка версии 54.0

## Пользовательский PDF dsjf.pdf

Проверен именно приложенный файл, SHA256 `03baa51997e1758942723c6a06b6d84b5ed797419c3137496227adee25d79931`.

- 9 страниц без извлекаемого текстового слоя; таблицы повёрнуты боком.
- Через реальный `/api/price-documents/preview`, без замены OCR или тарифных данных: **220 направлений, 6 160 значений, 0 пропущенных строк**. В этом окружении обработка и проверки экспорта заняли 173,45 секунды.
- По заголовку определены Санкт-Петербург и дата 03.08.2026; НДС — «С НДС (по источнику)». Межтерминальная таблица на страницах 1–5; разделы доставки и услуг не подмешаны.
- Через подтверждение API сохранены цены и неизменённый исходный PDF; документ выбран для своих маршрутов и доступен в общем списке.
- Для Санкт-Петербург → Москва проверены: до 1 кг — 610 руб.; опубликованный минимум — 880 руб.; 100 кг — ставка 14,90 руб/кг и стоимость 1 490 руб. Значение для 20 000 кг отсутствует. Обратный маршрут не создан.
- Выгружены отдельный XLSX маршрута (листы «Маршрут», «Источники») и книга структуры эталона. Проверены числовые ячейки, источник OCR, страница, дата; проверено использование файла при сборке большой таблицы.
- Отдельно визуально сверены строки, где потребовалось повторное чтение: Калуга, Качканар, Переславль-Залесский, Сыктывкар и Тамбов. Разделители десятичных дробей прочитаны из изображений, не восстановлены делением числа на 100.

## Регрессии

Полный прогон: **200 Python-тестов, PASS**, 240,188 секунды.

- 25 существующих тестов импорта, общей библиотеки и обратной совместимости: PASS.
- 6 новых тестов OCR: PASS. Реальное распознавание повёрнутого растрового PDF, суммы/ставки/дата/НДС, отсутствие tesseract и pdftoppm в PATH, неверный маршрут/компания, отказ от угадывания запятых, общая библиотека, отдельный импорт, Excel и повторное использование OCR в одном сеансе.
- 9 наборов тестов интерфейса jsdom: PASS, включая обе темы, загрузку, выбор источника, фильтры, графики и обе выгрузки.

Синтетические/исторические тарифы в `tests/fixtures` используются только тестами. Приложение не читает их как источник цен. В поставку не включены runtime, пользовательская библиотека, результаты OCR dsjf.pdf, рабочие цены, сетевой кэш или ключи доступа.

## Проверка поставки

Архив распакован в чистую папку, сервер запущен по HTTP. Версия 54.0, 17 компаний, 127 назначений на каждое основное отправление. Библиотека пуста, рабочие цены и ячейки отдельного Excel пустые; обе темы и отдельная выгрузка доступны. Из распакованной поставки через API распознан тестовый скан: 28 строк, исходная дата, НДС и OCR-источник, без внешнего исполняемого Tesseract.

## Пределы проверки

OCR включён для указанного макета ДЛ, а не произвольных таблиц всех компаний. Совпадение нескольких чтений уменьшает риск, но не доказывает безошибочность: пользователь подтверждает цены после сверки. Дата файла не заменяется датой загрузки; файл пользователя не помечается LIVE. Сайты перевозчиков в этой задаче заново не проверялись. Зависимости проверены в Linux; запуск Windows cmd обновлён, интерактивный запуск на Windows здесь не выполнялся.

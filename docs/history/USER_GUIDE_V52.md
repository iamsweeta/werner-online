# Цены, источники и PDF Деловых Линий

## Как работать с ценами

1. Откройте «Один маршрут» и выберите города. Сразу появятся ранее сохранённые результаты, если по этому направлению уже был успешный сбор или подтверждён импорт.
2. Нажмите «Обновить маршрут», когда нужны новые данные. Открытие страницы и смена веса не запрашивают сайты.
3. Посмотрите статус каждой компании. «Обновлено · LIVE» — успешная проверка не более 30 минут назад. «Сохранённая цена» — ранее полученный результат с датой. «Не обновилось · прежняя цена» — попытка не подтвердила новую цену; используется предыдущая. «Файл пользователя» — ваш подтверждённый документ.
4. При частичном ответе обновляются только полученные веса. Остальные сохраняют свои прежние значения и даты. В разделе «Источники» доступны ошибка и исходный файл. Если источник теперь сообщает «по запросу», прежняя цена сохраняется как историческая, с этим пояснением.
5. Если цены никогда не было, она остаётся пустой. Минимум и отсутствующие диапазоны не угадываются.
6. «Скачать Excel маршрута» выгружает показанные источники в отдельный XLSX. Общая таблица создаётся в отдельном разделе. «Собрать из текущих данных и прайсов» работает без новых запросов к перевозчикам; «Обновить онлайн и собрать таблицу» запускает новый сбор.

## Как загрузить PDF ДЛ из Москвы

1. Откройте https://www.dellin.ru/documents/ → «Тарифы на услуги» → «Автодоставка грузов в регионы из города» → «Москва». Прямая ссылка: https://www.dellin.ru/pricelist_pdf/?city=3&is_region=0&is_future=0.
2. Скачайте PDF. Имя `pricelist.pdf'` теперь принимается и автоматически исправляется. Проверяется само содержимое, а не только расширение: HTML ошибки сайта не считается PDF.
3. Для всех направлений файла откройте «Прайс-листы», выберите «ДЛ», «Москва» и файл. Нажмите «Распознать маршруты и цены». В предпросмотре переключите маршрут, сверьте цены и дату с оригиналом, подтвердите проверку и нажмите «Сохранить прайс-лист».
4. Для одного направления можно использовать кнопку загрузки прайса в «Одном маршруте». Город отправления должен совпадать с заголовком PDF.
5. Вернитесь к сравнению. Для большой таблицы нажмите «Пересобрать Excel с прайсами» или «Собрать из текущих данных и прайсов».

Распознаётся текстовый PDF ДЛ с первой межтерминальной таблицей. Таблицы адресной доставки, упаковки и допуслуг не подменяют тариф между городами. В проверенном макете есть 28 строк из 29 контрольных профилей, включая МИН; тарифа 20 000 кг там нет. Недостающая цена не достраивается.

Если текст нельзя выделить, это скан: встроенного OCR нет. Используйте текстовый PDF или XLSX-шаблон. Если заголовок таблицы изменился, приложение покажет ошибку и не применит сомнительные числа. При сохранении проблемы приложите сам PDF, а не скриншот ошибки, чтобы проверить его конкретный макет.

## Где хранятся данные

Цены и подтверждённые файлы сохраняются на диске сервера приложения, без срока автоматического удаления. При локальном запуске это папка `runtime` на вашем компьютере. 30 минут — срок отметки LIVE и отдельный срок неподтверждённого предпросмотра, но не срок хранения сохранённых прайсов.

При обновлении версии переносите всю `runtime` при остановленной программе. На хостинге используйте постоянный диск и `TARIFF_DATA_DIR`, одинаковый при каждом запуске. В браузере хранятся только настройки интерфейса, а не ваши прайсы. Кнопка резервной копии прайсов сохраняет пользовательские документы; для переноса онлайн-истории нужна вся папка данных.

## Ограничение онлайн-доступа

Апостроф мешал ручному импорту, но не был причиной защиты сайта: онлайн-загрузчик определяет PDF по содержимому. При прямой проверке из среды разработки 20 сентября 2026 года сервер ДЛ вернул HTTP 401 и HTML. Работа ручного импорта подтверждена на официальном московском PDF, сохранённом как тестовый образец; конкретный PDF, который не открылся у заказчика, к последнему сообщению не приложен. Доступность ДЛ и Байкал Сервиса зависит от ответа их сайтов; неудачная проверка сохраняет ранее полученные цены, но не создаёт новых.

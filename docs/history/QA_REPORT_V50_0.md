# Проверка версии 50.0

Дата проверки: 15 сентября 2026.

## Проверенные источники

Фактически скачаны официальные XLSX Werner для Москвы и Санкт-Петербурга и общий прайс Фортуны со страницы https://fte.ru/price/. URL, время загрузки и SHA256 записаны в `docs/LIVE_CHECK_V50.json`.

- Werner: 127 исходящих маршрутов из Москвы и 127 из Санкт-Петербурга; на каждом проверяются все 28 контрольных весов непосредственно по исходной строке документа. Дата тарифов в обоих файлах — 10.08.2026. Прямой адрес на сайте доступен, страница каталога ранее давала тайм-аут.
- Фортуна: 438 автомобильных направлений из 19 городов; 28 весов и минимум для каждого. Значения проверяются непосредственно по исходным ячейкам. 50 оставшихся направлений в документе имеют договорные цены либо отдельные железнодорожные строки без автотарифа. Это отсутствие сопоставимой опубликованной цены, а не число, которое можно восстановить догадкой.
- Реальные файлы сохранены только как тестовые примеры в `tests/fixtures`; приложение не использует их для заполнения рабочего Excel.

## Проверки приложения

- Полный набор Python: 166 тестов (парсеры, происхождение и актуальность данных, фильтры, сохранение, несколько документов, маршруты, общая и отдельная выгрузки, миграция).
- Пять сценариев jsdom: обновление и повторные попытки, выбор направлений, загрузка и подтверждение документов, большая таблица, два режима единиц и переключение темы.
- Полный отчёт на синтетических данных: 17 компаний × 254 маршрута, проверены 125 222 числовые ячейки, 43 листа. Ни одной сетевой загрузки в режиме документов. Тестовые цены в рабочие данные не включены.
- Excel независимо открыт и пересчитан: ошибок формул не найдено, значения и ссылки на графики совпали. Просмотрены изображения листов «Графики» и WernerNEW. У невыбранной компании формульные ячейки отображаются пустыми, а не нулевыми.
- Проверены отсутствие встроенных цен на чистой установке и игнорирование специально подложенного старого ценового файла; оба фильтра экспорта оставляют недоступные цены пустыми.
- Контраст обычного текста и кнопок проверен численно в обеих темах: не ниже 4,5:1. Сохранены адаптивные стили и карточки сравнения на узком экране. Реальный Chromium в этой среде не запустился; проверка UI выполнялась через jsdom и CSS, не через скриншоты браузера.
- Итоговый ZIP проверен распаковкой и запуском HTTP-приложения; runtime, API-ключи и тестовые рабочие базы в архив не включаются.

## Границы результата

Проверка трёх текущих файлов не означает непрерывную доступность всех 17 сайтов. Все остальные адаптеры сохранены и проходят регрессионные тесты; их постоянную онлайн-доступность эта проверка не подтверждает. При отсутствии опубликованной цены нужна актуальная документация клиента.

Эталон задаёт форму, не данные. Excel после скачивания является снимком: обновление запускается в приложении с последующей новой выгрузкой. До 50 кг в эталоне используются суммы, с 100 кг — опубликованные ставки; переключатель интерфейса этого правила не меняет. Произвольные сканы PDF без текста требуют подготовки XLSX; OCR не добавлен.

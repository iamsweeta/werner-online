# Проверка v45.0

Проверено 14.09.2026 в Linux / Python 3.12. Нативный запуск Windows не выполнялся; команда запуска и порт проверены тестами.

## Программные проверки

- 112 Python-тестов: успешно. Регрессии загрузчиков, направлений, свежести и Excel; новые проверки импорта для всех 18 компаний через общий шаблон, нативных PDF/XLS/XLSX, ZIP, даты, дубликатов, неверной компании и обратного маршрута.
- HTTP-проверка работающего сервера: версия 45.0, 18 компаний, загрузка PDF ДЛ (28 строк), применение 100 кг = 1 480 ₽ как пользовательского источника, скачивание идентичного оригинала, Excel и отключение импорта — успешно.
- Два сценария интерфейса jsdom: успешно. Сохранение маршрута и обновление; импорт с предпросмотром и подтверждением, отображение пользовательского источника, матрица, фильтры и отключение импорта.
- Оригинал PDF ДЛ визуально сверен: строка Санкт-Петербурга на странице 4 соответствует весовым колонкам; колонка объёма не подставляется вместо ставки за кг.
- Файлы пользователя хранятся отдельно от LIVE. Повторная онлайн-загрузка не изменяет их происхождение. Повторный/истёкший предпросмотр и изменённый после распознавания файл отклоняются.
- Для PDF ДЛ распознаны 28 из 29 строк: 20 000 кг не опубликованы в используемой таблице. Подтверждён многострочный город Петропавловск-Камчатский.
- Общий PDF содержит явно заданные компанию и направление. Синтетическая фикстура помечена как тестовая; никогда не используется для LIVE.

## Практические ограничения

Дата импорта не подтверждает актуальность тарифов. Разные PDF-макеты и сканы не распознаются произвольно; для них доступен XLSX-шаблон. Прайс пользователя имеет приоритет до отключения. Предпросмотр действует 30 минут. Гарантировать доступность сторонних сайтов и наличие цены каждой компании на любом маршруте невозможно; неподтверждённые числа не подставляются.

При добавлении новой схемы документа нужен отдельный парсер с проверкой направления, единиц, диапазонов и исходной таблицы. Источник «Ссылка из браузера заказчика» не заменяет скачанный официальный документ.

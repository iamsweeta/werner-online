# Проверка 55.0 · фоновый импорт одного маршрута

## Подтверждённый дефект

В 54.0 браузер вызывал синхронный `/api/import/preview` и ждал полного OCR. Обработка пользовательского PDF занимает несколько минут. Тайм-аут 630 секунд в JavaScript не менял тайм-ауты внешнего хостинга/прокси. Пользователь подтвердил, что 502 появилась в «Одном маршруте». Серверные журналы его хостинга не предоставлены, поэтому конкретная причина ответа 502 на этом сервере остаётся неподтверждённой.

В 55.0 интерфейс отправляет файл в `/api/import/jobs` (HTTP 202) и читает готовность короткими запросами. Старый синхронный API остаётся для совместимости; интерфейс им не пользуется.

## Реальный HTTP-тест на пользовательском PDF

Использован исходный `dsjf.pdf`, без подмены OCR/парсера/чисел. Сервер Uvicorn запущен в отдельном процессе с чистым каталогом данных. Для загрузки, опроса статуса и проверки здоровья задан лимит **1 секунда на запрос**.

| Проверка | Результат |
|---|---|
| Подтверждение приёма 4,5-МБ PDF | HTTP 202 за **0,534 с** |
| Максимальная длительность запроса статуса | **0,374 с**, 243 опроса |
| Полная обработка и проверки | **250,23 с**, OCR в фоне |
| Маршрут | Санкт-Петербург → Москва |
| Предпросмотр | 28 строк, источник OCR, страница 3 |
| Контрольные значения | до 1 кг — 610 руб.; 100 кг — 1490 руб. |
| Подтверждение | Цены сохраняются в общую библиотеку только после commit |
| Исходный PDF | Получен обратно побайтно без изменения |
| Excel отдельного маршрута | Два листа «Маршрут», «Источники»; проверено числовое значение |
| После применения | Состояние задания «committed», повторный OCR не запускается |

## Автоматические проверки

**99 Python-тестов — PASS** (25 целевых + 74 регрессионных, без пересечения наборов):

- Ответ приёма и чтение статуса не ждут заблокированного парсера; `/health` продолжает работать.
- Повтор POST с тем же идентификатором не создаёт второе распознавание; другой файл/маршрут с тем же идентификатором отклоняется.
- Готовый результат доступен из другого процесса через SQLite с тем же каталогом данных.
- Проверены явное подтверждение, изоляция обратного направления, ошибки парсера, исчезновение сигнала рабочего процесса, истечение предпросмотра и лимит одновременных заданий.
- Прогресс OCR сохраняется. В резервную копию подтверждённых прайсов не попадают временные задания.
- Прежние импорты, OCR, библиотека, таблицы, хранение, маршруты и сетевые механизмы проверены соответствующими регрессионными тестами.

**10 наборов UI-тестов jsdom — PASS**. Новый набор воспроизводит временную 502 при чтении статуса, потерю ответа POST после принятия файла и перезагрузку страницы. Во всех случаях файл отправляется один раз, предпросмотр восстанавливается, цены не применяются автоматически. Остальные тесты проверяют обе темы, графики, выбор документов и экспорт.

## Границы проверки

Хостинг пользователя не обновлялся: для применения исправления нужно заменить приложение и перезапустить работающий сервер. Ошибка 502 также возможна при недоступности/перезапуске сервера или нехватке его ресурсов; фоновые запросы не гарантируют исправление таких причин. Настройки прокси не менялись.

Новые тарифные константы или заполненные рабочие кэши не добавлены. Подтверждённые документы и ранее сохранённые цены не изменяются при ошибке распознавания. Полный прогон 200 тестов версии 54.0 — исторический; для этой версии выполнены перечисленные 99 тестов и 10 UI-наборов.

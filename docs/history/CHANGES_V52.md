# Версия 52.0

- Исправлены имена прайсов с лишними кавычками/апострофами, включая `pricelist.pdf'`: одиночная загрузка, несколько документов, ZIP. Проверка содержимого PDF сохранена; файл `.pdf.exe` не принимается.
- При открытии показываются последние сохранённые цены и документы. Автоматический запуск сбора при входе, смене маршрута/веса, вкладки и простое удалён. Уже запущенный сбор продолжает отображаться без дублирования.
- Ошибки и неполные ответы не удаляют прежние онлайн-строки. Исторические цены сохраняют дату, источник и отдельную отметку. Новый ответ «по запросу» не превращает старую цену в текущую.
- Сохранённые цены включаются по умолчанию в отдельный Excel маршрута и общий отчёт; в источниках и счётчиках отличимы от обновлённых.
- График разделён на 0–50, 100–1500 и 1500–5000 кг.
- Добавлены пояснения «Источников», пошаговая загрузка ДЛ, настройка постоянной папки `TARIFF_DATA_DIR` для хостинга и инструкция переноса данных.
- Сохранены белая/тёмная темы, два режима единиц, отдельный Excel маршрута, структура большого Excel, проверка и подтверждение файлов. Цены не встроены в рабочие данные.

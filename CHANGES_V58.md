# Изменения 58.0

- Большой Excel использует общую базу последних успешных онлайн-цен и подтверждённых документов, включая результаты других запусков и вкладки одного маршрута.
- Основные 254 направления остаются в отчёте целиком даже при остановленной загрузке без новых результатов. Пропуски остаются пустыми, исходные тарифы заказчика из шаблона не берутся.
- Новое сохранение онлайн-цен или изменение библиотеки делает прежний экспорт устаревшим; интерфейс предлагает пересобрать файл.
- Очередь онлайн-проверок ограничена 7 работающими компаниями. Остановка прекращает запуск остальных, дожидается уже работающих и сохраняет каждую. Продолжение большого сбора пропускает завершённые компании.
- Остановка доступна также для онлайн-обновления одного маршрута. История позволяет вернуться к ранее остановленным большим загрузкам.
- Дополнительные действия, шаблоны, диагностика, хранение и фильтры убраны в раскрывающиеся блоки. Выбор маршрута показывает данные автоматически.
- Добавлены ползунки границ тяжёлого графика 100 кг–20 т; сохранены быстрые масштабы. Малые отправки 0–50 кг отображаются на графике в рублях за отправку.
- Ускорен OCR PDF с векторными контурами вместо текстового слоя: образцы только из этого документа, подтверждённые OCR, контрольная строка на каждой странице, обычный OCR при неоднозначности.
- Повторный разбор точного файла использует ограниченный дисковый кэш; полный результат может обслуживать один маршрут. Частичный результат не заменяет полный документ и не подтверждается автоматически.
- Исходные документы, явное подтверждение, обе выгрузки, источник/дата каждой цены, светлая и тёмная темы сохранены.

# Как загрузить скан Деловых Линий

1. Распакуйте весь архив приложения в новую папку. До запуска перенесите папку `runtime` из предыдущей установки, если хотите сохранить свою библиотеку. Если используете постоянный `TARIFF_DATA_DIR`, оставьте тот же каталог.
2. Запустите `START_WINDOWS.cmd`. Он установит компоненты OCR вместе с остальными зависимостями. Отдельно устанавливать Tesseract не нужно. Для Linux/macOS: `python -m pip install -r requirements.txt`, затем `python launch.py`.
3. Откройте **Прайс-листы**, выберите **ДЛ**. В поле **Откуда** оставьте **Определить из файла**. Загрузите PDF и нажмите **Распознать маршруты и цены**.
4. Дождитесь обработки: при OCR показывается номер страницы. Большой документ может обрабатываться несколько минут. Для сканов действуют лимиты: 40 страниц, 20 МБ, 10 минут на документ. Не нужно вручную поворачивать страницы или исправлять апостроф в имени `pricelist.pdf'`.
5. Проверьте дату, направления, фиксированные суммы, минимум и ставки. Выбор маршрута в предпросмотре показывает его цены и страницу оригинала. Нераспознанные строки перечисляются отдельно и не применяются. OCR не гарантирует отсутствие ошибок: требуется сверка с оригиналом.
6. Подтвердите проверку и сохраните документ. Файл станет общим источником для своих направлений. В **Одном маршруте** выберите нужные города и документ в блоке **Прайсы для этого маршрута** либо перейдите из библиотеки кнопкой **Выбрать маршрут из файла**.
7. **Скачать Excel маршрута** создаёт отдельный файл выбранного направления. Для общей таблицы откройте **Большая таблица** и нажмите **Собрать из текущих данных и прайсов**. После изменения библиотеки отчёт нужно пересобрать.

## Поддержка и хранение

В этой версии OCR поддерживает сканы межтерминальной таблицы ДЛ в проверяемом макете. Текстовые PDF и остальные поддерживаемые Excel/CSV/ZIP работают как раньше. Для другого сканированного макета используйте XLSX-шаблон.

Распознавание проходит на компьютере/сервере приложения, без отправки документа в сторонний OCR-сервис. Модели русского и английского уже в архиве. Приложение сохраняет исходный PDF без изменений и подтверждённые цены бессрочно в `runtime/imports` (либо в `TARIFF_DATA_DIR/imports`). Временная рабочая копия OCR удаляется после обработки. Неподтверждённый предпросмотр действует 30 минут; его временные файлы очищаются при последующих загрузках. Кнопка «Отключить» прекращает использование документа, сохраняя оригинал. Резервная копия доступна в библиотеке.

Для выбранного документа используются подтверждённые цены из этого файла. Вариант «Автоматически» возвращает онлайн-приоритет. Ни OCR, ни экспорт не заполняют отсутствующие цены примерными значениями из эталона.

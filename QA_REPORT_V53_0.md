# Проверки версии 53.0

## Результат

- Python: **194 теста, OK**, 318,853 с. Команда: `python -m unittest discover -s tests -v`.
- Интерфейс: **9 наборов jsdom-проверок, PASS**. Проверка библиотеки повторена после окончательной правки полного каталога маршрутов — PASS.

## Проверено по текущему запросу

1. Документ, подтверждённый в общей библиотеке, сразу доступен в API одного маршрута и весовой матрице. При выбранном документе его тариф имеет приоритет перед отличающимся свежим онлайн-тарифом; источник остаётся документом, а не LIVE.
2. Та же сумма попадает в отдельный XLSX маршрута, а опубликованная ставка — в соответствующую ячейку большого Excel. Проверено применение выбора при заполнении общего отчёта.
3. Загрузка из диалога одного маршрута появляется в общей библиотеке с оригиналом и списком сохранённых направлений.
4. Старые подтверждённые JSON-загрузки регистрируются в библиотеке однократно. Повторное чтение и очистка кеша миграции не создают дубликаты и не включают отключённый файл повторно.
5. Можно выбрать прежнюю активную версию прайса. Выбор относится только к данной компании и направлению; обратное направление сохраняет свой источник. Выбор сохраняется после запуска нового процесса и входит в SQLite-базу резервной копии.
6. Нельзя назначить документ другой компании, другого направления или отключённый документ. Смена выбора увеличивает общую ревизию документов, которая используется для пометки старого Excel как требующего пересборки.
7. В интерфейсе проверены выбор файла, применение, обновление цены, снятие фильтра «Только LIVE», возврат к автоматическому источнику, переход из библиотеки в один маршрут и использование полного каталога городов.
8. Прежние проверки импорта PDF ДЛ с апострофом, сохранённых цен, пустых ячеек, двух единиц измерения, трёх масштабов графика, белой/тёмной тем, отдельного Excel маршрута и структуры большой таблицы сохранены.

## Изменение приоритета

После подтверждения новой загрузки файл выбирается для распознанных из него направлений. Для использования онлайн-приоритета нужно выбрать «Автоматически» и нажать «Применить». Автоматический режим сохраняет прежнюю последовательность источников: свежий онлайн-ответ, документ, последнее сохранённое онлайн-значение. Отсутствующие веса и ставки за кг не выдумываются.

## Границы проверки

Это проверка приложения и обмена данными между его разделами. Нового аудита доступности всех сайтов перевозчиков не проводилось. Цены в тестах изолированы от рабочих данных; архив поставляется без runtime, пользовательских файлов и сетевого кеша. Браузерный интерфейс проверен через DOM и события jsdom; визуальный прогон на физическом телефоне и запуск Windows в этой среде не выполнялись.

Для сохранения старых данных при обновлении перенесите всю папку runtime при остановленном приложении либо используйте прежний TARIFF_DATA_DIR. Подтверждённые документы мигрируют в общую библиотеку автоматически, повторная загрузка не нужна.

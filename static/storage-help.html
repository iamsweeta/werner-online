Хранилище и перенос данных

Проверяю настройки…

1. Проверить подключение

Проверка запишет небольшой пробный файл в облако, прочитает его и удалит. Прайсы не меняются.

2. Перенести прежние данные

Выберите ZIP, скачанный кнопкой «Скачать резервную копию данных» на прежней версии сайта. Архив приложения сюда не подходит. Перенос возможен только в пустую облачную базу и не заменяет уже сохранённые цены.

Если данных для переноса нет, пропустите этот шаг.

После завершения откройте «Один маршрут» или «Большую таблицу». Если Render прервал перенос, откройте эту страницу снова. Цены из архива применяются целиком после проверки.

Резервная копия

Копия включает библиотеку прайсов, оригиналы, ручные и последние онлайн-цены, выбор источников и историю большой таблицы. API-ключи и временные предпросмотры не включены.

Скачать резервную копию данных

Если облако ещё не подключено

  1. Перед обновлением сайта скачайте резервную копию.
  2. Откройте инструкцию SETUP_RENDER_NEON.html из архива версии 63.
  3. Создайте бесплатный проект Neon в AWS Frankfurt, базу и закрытый файловый бакет.
  4. Добавьте настройки из render.env в Render → Environment. Не загружайте этот файл в GitHub.
  5. После развёртывания откройте эту страницу, проверьте подключение и перенесите резервную копию.

Что сохраняется и на какой срок

Подтверждённые прайсы, оригиналы и ручные цены не удаляются приложением по сроку. Через месяц они доступны из облака без повторной загрузки. Последние онлайн-цены остаются, но отметка LIVE снимается через 30 минут. Это не подтверждает их актуальность на новый месяц.

Предпросмотр необходимо подтвердить в течение 30 минут после распознавания. Прерванный скан можно распознать повторно из сохранённого файла в пределах срока предпросмотра. Распознавание начнётся заново; уже подтверждённые цены не меняются.

На Render Free первый запуск после простоя может занимать около минуты. Облачная база сохраняет данные, но не отменяет ограничения бесплатного сервера на обработку сканов.

Проверить после перезапуска

  1. Откройте известный маршрут и запомните цену из применённого прайса.
  2. Скачайте оригинал из библиотеки — файл должен открыться.
  3. В Render перезапустите сервис.
  4. Откройте тот же маршрут: цена, файл и история большой таблицы должны остаться. Новое онлайн-обновление не требуется.

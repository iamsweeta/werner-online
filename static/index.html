Как обновляются данные и работает продолжение?

Окно приложения должно оставаться запущенным во время сбора. После перезапуска нажмите «Продолжить». Выбранный документ имеет приоритет для его строк в обоих разделах. Вариант «Автоматически» возвращает онлайн-приоритет. Новый Excel использует общую базу всех загрузок. При остановке весь выбранный список направлений остаётся в отчёте. Скачанный файл сам не обновляется: соберите его снова.

В приложении подключены 17 компаний и весовые тарифы. Остальные листы эталона и объёмные колонки сохраняют структуру с пустыми ценовыми ячейками. Сбор всех пар городов может занять дни. Более 400 маршрутов выгружаются в несколько Excel-файлов внутри ZIP. Если цена никогда не была получена, ячейка остаётся пустой; причина указана в источниках. При неудачном обновлении сохраняется прежняя цена с исходной датой.

Онлайн-прайсы и последние сохранённые значения

Как читать источники. «Обновлено · LIVE» — цена получена при последней успешной проверке, не более 30 минут назад. «Сохранённая цена» — последний успешный результат с указанной датой; он остаётся видимым после простоя. «Не обновилось» — новая попытка не подтвердила цену, показана прежняя. «Файл пользователя» — цена из документа, который вы проверили и сохранили. «Выбранный файл» — назначенный вами документ; его строки имеют приоритет в обоих разделах.

«Открыть источник» ведёт на сайт компании, «Скачанный прайс» — к исходному документу. Если сайт недоступен, откройте «Прайс-листы», выберите компанию и город отправления, загрузите файл, проверьте предпросмотр и нажмите «Сохранить прайс-лист». Пустая ячейка означает, что подтверждённой цены ещё не было. Перезапуск и смена вкладки не запускают новый сбор.

Прайс ДЛ из Москвы: на странице «Документы» ДЛ выберите Москву в строке «Автодоставка грузов в регионы из города» и скачайте PDF. В приложении выберите «ДЛ» и «Москва», загрузите файл, нажмите «Распознать маршруты и цены», проверьте и сохраните. Имя pricelist.pdf' исправляется автоматически; переименовывать файл не нужно. Подходит текстовый PDF или скан с первой таблицей «Тарифы на межтерминальную перевозку из …». Для прайса из Санкт-Петербурга выберите Санкт-Петербург или «Определить из файла».

Прайсы хранятся бессрочно на сервере приложения (при локальном запуске — на вашем компьютере). «Отключить» убирает цены из расчётов, но сохраняет оригинал. Неподтверждённый предпросмотр действует 30 минут.

В Excel эталона до 50 кг и МИН записываются суммы отправки, от 100 кг — ставки из прайса. На экране единицы выбираются переключателем. Общая строка использует свой верхний контрольный вес. Неоднозначные цены не угадываются.

    Мои документы

    Загрузить прайс компании

    Из файла сохраняются проверенные цены указанной компании и направления. Для распознавания всех маршрутов документа используйте общую библиотеку. После подтверждения файл добавится в общую библиотеку и будет выбран для этого направления в обоих разделах. Для возврата к онлайн-приоритету выберите «Автоматически» в блоке «Прайсы для этого маршрута». Если нет новой онлайн-цены или документа, показывается последнее сохранённое значение с датой.

    Какие документы можно загрузить?

    Апостроф после расширения, например pricelist.pdf', исправляется автоматически. Город отправления должен совпадать с заголовком: для прайса «из Санкт-Петербурга» выберите Санкт-Петербург, для московского — Москву. В библиотеке можно оставить автоматическое определение города.

    ДЛ — текстовый PDF или скан с первой таблицей межтерминальных тарифов; Возовоз — Excel или ZIP с листом «Тарифы межтерм.перевозок»; КИТ и Новая Линия — текстовый PDF; Фортуна, ЭкспедицияПлюс, ПЭК и Рейл Континент — XLSX основного прайса.

    Для всех компаний доступен единый XLSX-шаблон. Общий текстовый PDF должен содержать «Компания: …», «Откуда: …», «Куда: …» и таблицу «Вес, кг | Цена, руб» с контрольными весами. Скан межтерминального прайса ДЛ распознаётся автоматически (OCR); страницы можно не поворачивать вручную. Распознавание идёт в фоне: окно можно закрыть. При повторном открытии для того же маршрута приложение проверит готовность. Цены применяются только после вашего подтверждения. До 40 страниц скана, до 10 минут обработки. Другие сканированные макеты требуют XLSX-шаблона. Проверьте цены перед подтверждением.

      Договорные API

      Публичные прайсы загружаются без ключей. Для некоторых точных калькуляторов нужен доступ к API перевозчика.

      По умолчанию используются прайсы, API и опубликованные цены «от». Браузерные калькуляторы могут заметно увеличить ожидание при недоступности сайта.

      Цена в ячейке

      Ручная цена сохраняется на сервере и используется в обеих выгрузках. Она будет помечена «Введено вручную». Новый применённый файл заменит её, если содержит этот вес.

# Настройка Render — версия 63

Для бесплатного Render с внешними PostgreSQL и файлами откройте [SETUP_RENDER_NEON.md](SETUP_RENDER_NEON.md) или SETUP_RENDER_NEON.html.

Предыдущая схема с локальной SQLite и платным Persistent Disk остаётся доступной в режиме TARIFF_STORAGE=local. Укажите TARIFF_DATA_DIR внутри диска. Для бесплатного варианта используйте TARIFF_STORAGE=cloud и все переменные из новой инструкции.

# Одна библиотека для всех таблиц

1. Откройте «Прайс-листы», выберите компанию, загрузите документ, проверьте предпросмотр и подтвердите сохранение. До подтверждения файл не участвует в расчётах.
2. После сохранения он автоматически применяется к распознанным направлениям. В списке файлов нажмите «Выбрать маршрут из файла», выберите направление и «Использовать в „Одном маршруте“».
3. Либо откройте «Один маршрут» обычным способом. В блоке «Прайсы для этого маршрута» будут только документы выбранных компаний с подтверждёнными ценами этого направления. Выберите нужный файл и нажмите «Применить».
4. В сравнении появится статус «Выбранный файл». Цена из него имеет приоритет перед онлайн-ценой для имеющихся в документе весов. Имя документа и дата видны в источниках. Неизвестные веса не достраиваются.
5. «Скачать Excel маршрута» использует тот же выбор и создаёт отдельный файл. В большой таблице нажмите «Пересобрать Excel с прайсами» либо «Собрать из текущих данных и прайсов». Выбор документа общий для обоих разделов.
6. Чтобы вернуть онлайн-приоритет, выберите «Автоматически · онлайн, затем библиотека» и «Применить». Это относится только к данной компании и направлению. Само применение источника не запускает сетевое обновление.

Загрузка через «Загрузить прайс для маршрута» тоже сохраняет файл в общей библиотеке, но распознаёт только выбранное направление. Чтобы использовать все направления большого PDF, загрузите его через «Прайс-листы». Обратное направление не подставляется автоматически.

Если библиотека есть, но подходящих файлов нет, проверьте компанию, город отправления и список распознанных направлений у документа. Файл может относиться к обратному направлению или не содержать нужную строку. Произвольная привязка чужого тарифа к новому маршруту запрещена.

Старые документы одного маршрута включаются в библиотеку автоматически. «Отключить» исключает документ из расчётов и снимает его выбор, оригинал сохраняется. Другую активную версию можно назначить явно.

Для переноса на новую версию сначала закройте приложение и скопируйте всю папку runtime в новую установку. При настроенном TARIFF_DATA_DIR используйте прежнюю постоянную папку. Сведения о файлах и выборе источников входят в резервную копию прайсов.

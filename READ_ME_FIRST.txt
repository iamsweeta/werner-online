ТАРИФЫ · 58.0

1. Распакуйте весь архив. Не запускайте файл внутри ZIP.
2. При обновлении перенесите runtime из прежней установки либо сохраните прежний TARIFF_DATA_DIR.
3. Windows: START_WINDOWS.cmd. Python 3.11+ должен быть установлен.
4. Сервер должен работать, пока загружаются цены или распознаётся документ.
5. Большая таблица → Основные · 254 → Собрать Excel из сохранённых цен.
   Для новых цен: Обновить цены онлайн. Остановить загрузку сохраняет готовые результаты.
6. Один маршрут сразу показывает сохранённые цены. Обновление — по кнопке.
7. Прайс-листы → компания → файлы → распознать → проверить → сохранить.

На хостинге обновите запущенное приложение и перезапустите его. Каталог данных должен быть постоянным.

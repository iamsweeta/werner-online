ТАРИФЫ · 56.0

1. Закройте прежнюю версию. Распакуйте весь архив в новую папку.
2. ДО запуска перенесите всю папку runtime из старой установки в новую: это ваши цены, документы, настройки и задания. Рабочие цены в новый архив не включены.
3. Запустите START_WINDOWS.cmd (Windows, Python 3.11+). Окно программы оставьте открытым.
4. В «Одном маршруте» сразу показываются последние сохранённые цены. Для загрузки новых нажмите «Обновить маршрут». Ошибка не стирает прежнее значение; дата и статус указаны у цены.
5. График: 0–50, 100–1500, 1500–5000 кг. Тяжёлые веса остаются в таблице и Excel.
6. ДЛ: выберите компанию ДЛ и город из заголовка PDF (Москва или Санкт-Петербург). Сканы распознаются автоматически; в одном маршруте читается только выбранная строка; в библиотеке можно определить город из файла. Имя pricelist.pdf' исправляется автоматически. Сначала распознавание и проверка, затем подтверждение сохранения.
7. «Скачать Excel маршрута» — отдельный файл. «Большая таблица» — отдельная общая выгрузка.
8. По ссылке данные хранятся на сервере. На хостинге нужен постоянный диск и TARIFF_DATA_DIR; подробнее README.md. При локальном запуске данные хранятся в runtime бессрочно. 30 минут — срок LIVE, а не срок хранения цен.

Пошаговые пояснения: USER_GUIDE_V56.md. Исправления: CHANGES_V56.md. Проверки: QA_REPORT_V56_0.md.

ОБЩАЯ БИБЛИОТЕКА: после подтверждения загрузки документ доступен обоим разделам. В «Одном маршруте» выберите файл в блоке «Прайсы для этого маршрута» и нажмите «Применить». Либо откройте нужное направление кнопкой «Выбрать маршрут из файла» в библиотеке. Для большой таблицы после выбора пересоберите Excel.

ИСПРАВЛЕНИЕ 502: в «Одном маршруте» файл теперь обрабатывается в фоне. Можно закрыть окно и открыть снова для того же направления. Временная потеря связи не отправляет файл повторно. Чтобы исправление заработало по ссылке, замените приложение на сервере, перезапустите его и обновите страницу.

УСКОРЕНИЕ OCR 56.0: выбранный маршрут больше не ждёт чтения всех цен документа. Видны текущий этап и время. Через 120 секунд без завершения этапа OCR останавливается с пояснением. Перезапустите сервер после обновления, затем загрузите незавершённый файл заново.

# Тарифы — версия 63.2

Основная инструкция для вашего сайта: **[UPDATE_V63_2.md](UPDATE_V63_2.md)** — обновление существующего сайта. Полная настройка: [SETUP_RENDER_NEON.html](SETUP_RENDER_NEON.html) (откройте в браузере) или [SETUP_RENDER_NEON.md](SETUP_RENDER_NEON.md).

В этой версии добавлено отдельное облачное хранение: PostgreSQL для цен/библиотеки/истории и S3-совместимое хранилище оригиналов. Render Free может оставаться сервером приложения. Перед обновлением скачайте резервную копию действующего сайта.

- Настройка Neon на компьютере: `SETUP_CLOUD_WINDOWS.cmd` или `python configure_neon.py`.
- Код приложения → GitHub; секреты из `render.env` → Render Environment; ZIP резервной копии → `/storage-guide` на новом сайте.
- `render.env` и прайсы в GitHub не загружать.
- Локальный запуск: `START_WINDOWS.cmd` или установка `requirements.txt` и `python launch.py`. Без `TARIFF_STORAGE=cloud` сохраняется локальный режим.
- Отчёт проверки: `QA_REPORT_V63_2.md`. Предыдущие отчёты описывают прежние версии.

## Быстрый показ сохранённых цен

Версия 63.2 убирает повторное чтение маршрута для каждой компании и получает таблицу
с диаграммой одним запросом. На проверочном стенде число SQL-запросов на один показ
маршрута уменьшилось с 216 до 6. Это не измерение скорости серверов перевозчиков.

Онлайн-оригиналы отправляются в S3 до короткой транзакции записи цен; медленная
отправка файла не удерживает общую блокировку цен. Статус сбора доступен во время
записи контрольной точки. При ошибке сохранения новая цена не считается сохранённой.
Подтверждённые цены, файлы и история остаются в прежних PostgreSQL/S3 без переноса.

## Свободный вход

В Render Environment задайте `APP_AUTH_MODE=public` и выполните новое развёртывание. Этот режим работает вместе с `TARIFF_STORAGE=cloud`, независимо от сохранённого `APP_PASSWORD`. Все посетители получают доступ к общей таблице, документам и изменению цен. Для закрытого режима: `APP_AUTH_MODE=password` и пароль минимум 12 символов. Если новая переменная отсутствует, сохраняется прежняя политика доступа.

Списки городов и компаний загружаются без чтения цен из базы. При недоступности сервера показывается постоянное сообщение с кнопкой повторной загрузки. В `/health` видны версия, `access_mode` и `storage_mode`; секреты не выводятся.

## Рабочие разделы

«Один маршрут» — сравнение и отдельный Excel-файл. «Большая таблица» — сбор и экспорт всех выбранных направлений по структуре заказчика. «Прайс-листы» — общая библиотека документов. Подтверждённые цены не имеют срока удаления в приложении; дата и тип источника показаны отдельно.

До 50 кг и минимум — суммы отправки. В большой таблице для тяжёлых весов используются опубликованные ставки. На экране и в отдельном маршруте доступен переключатель суммы и расчётной цены за кг. Неизвестные цены остаются пустыми в Excel. Предустановленных рабочих цен нет.

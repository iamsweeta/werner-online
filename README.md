# Тарифы перевозчиков · 58.0

Приложение сравнивает тарифы 17 перевозчиков, сохраняет полученные цены и заполняет Excel в структуре заказчика. Рабочих тарифов в установке нет: цены появляются из ответов источников и подтверждённых пользователем прайсов. Тестовые данные в `tests/fixtures` приложением не загружаются.

## Запуск и обновление

Windows: распакуйте весь архив и запустите **START_WINDOWS.cmd**. Нужен Python 3.11+; зависимости установятся автоматически. Linux/macOS: `python -m pip install -r requirements.txt`, затем `python launch.py`.

**Перед обновлением закройте старое приложение и перенесите его папку `runtime` в новую установку.** Если используется `TARIFF_DATA_DIR`, оставьте тот же постоянный каталог. Веб-сервер: обновите код, сохраните каталог данных и перезапустите сервер. Обновите страницу браузера. Скачивание архива не обновляет размещённое приложение автоматически.

На хостинге `TARIFF_DATA_DIR` должен указывать на постоянный диск. Очистка временного диска хостингом или запуск в новой папке без переноса `runtime` означает новую пустую установку. Приложение не может восстановить удалённый сервером каталог.

## Три раздела

- **Большая таблица.** Выберите список маршрутов. «Собрать Excel из сохранённых цен» использует общую базу всех загрузок и подтверждённые файлы, без обращения к сайтам. «Обновить цены онлайн» проверяет сайты, сохраняет каждый ответ и затем создаёт отчёт. «Основные · 254» всегда содержит все 254 направления, в том числе после остановки сбора. Более 400 направлений разбиваются на Excel-файлы внутри ZIP.
- **Один маршрут.** Сохранённые данные показываются сразу при выборе направления. Онлайн-обновление запускается только кнопкой. Excel скачивается отдельным файлом с листами «Маршрут» и «Источники». На графике 0–50 кг показана сумма отправки в ₽; масштаб тяжёлых грузов можно ограничить ползунками от 100 кг до 20 т.
- **Прайс-листы.** Загрузите один или несколько документов одной компании, проверьте предпросмотр и подтвердите. Общая библиотека используется обоими разделами. Неподтверждённый OCR не записывает цены в рабочую таблицу.

Остановка запрещает запуск новых компаний. Уже выполняющиеся проверки компаний завершатся и сохранят результат. «Продолжить» запрашивает только оставшиеся компании, а «Повторить неудачные проверки» — компании с ошибками/неполной сеткой. Предыдущие задания доступны в раскрывающемся блоке «Предыдущие загрузки и продолжение».

## Откуда цены и как долго они хранятся

Последние успешные онлайн-цены сохраняются в `runtime` бессрочно. После 30 минут исчезает только отметка LIVE. Ошибка обновления не удаляет ранее полученную цену; её источник и исходная дата остаются видимыми. Открытие страницы, выбор маршрута и перезапуск не инициируют новые запросы к перевозчикам.

Подтверждённые документы и оригиналы также хранятся бессрочно. «Отключить» исключает файл из расчётов, но оставляет оригинал. Предпросмотр до подтверждения действует 30 минут. Локальный кэш проверенного OCR — 7 дней, не более 64 записей / 32 МБ; очистка происходит при обращении к кэшу или проверке хранения. Он привязан к SHA256 всего файла, компании, версии алгоритма и области распознавания. Кэш не означает подтверждение или актуальность прайса и не содержит копии исходного PDF.

В автоматическом выборе источника используется свежая подтверждённая онлайн-цена, затем подтверждённый файл, затем последняя сохранённая онлайн-цена. Явно выбранный пользователем документ имеет приоритет для содержащихся в нём весов. При изменении данных готовый Excel помечается устаревшим — его нужно пересобрать. Уже скачанный файл сам по себе не обновляется.

## Excel заказчика

Структура, листы, заголовки и оформление берутся из очищенного шаблона `data/export_template.xlsx`. Значения тарифов берутся только из рабочей базы. До 50 кг и МИН — суммы в рублях; от 100 кг — опубликованные ставки в руб/кг. Если источник дал только общую сумму тяжёлой отправки, опубликованная ставка не выдумывается. Неизвестные цены и неподключённые объёмные тарифы остаются пустыми. Дополнительные листы «Источники» и «Сбор» поясняют происхождение и покрытие.

## OCR и ограничения

Текстовые PDF, Excel, CSV, ZIP и сканы первой межтерминальной таблицы ДЛ поддерживаются согласно подсказкам компании. Апостроф после `.pdf` удаляется из имени автоматически; формат дополнительно проверяется по содержимому. Для других сканированных макетов предусмотрены шаблоны XLSX/CSV; универсального распознавания любого документа нет.

Векторный PDF с контурами вместо текста читается по образцам цифр, проверенным двумя OCR-чтениями в этом же документе. Каждая страница имеет контрольную строку. Неизвестные или неоднозначные контуры, изображения, перекрытия и нестандартный макет возвращают обычный OCR. Для растрового скана остаётся сверка нескольких чтений чисел. Проверьте цены и направление по оригиналу перед применением.

Тестовый `dsjf.pdf`: отправление **Санкт-Петербург**, дата **03.08.2026**, 220 маршрутов. Это не московский прайс. Сам файл клиента в архив приложения не включён.

Сайты могут быть недоступны, требовать авторизацию или не публиковать конкретный маршрут. Нет гарантии получения всех цен с каждого сайта. Новых сетевых проверок перевозчиков эта версия не проводила: работа сосредоточена на общей базе, Excel, остановке загрузки, интерфейсе и OCR. Сохранённая старая цена и файл пользователя не выдаются за актуальный LIVE.

# Тарифы перевозчиков · 61.0

Приложение сравнивает тарифы перевозчиков, сохраняет подтверждённые прайсы и выгружает отдельный маршрут или большую Excel-таблицу в структуре заказчика.

## Запуск и обновление

Windows: распакуйте архив целиком и запустите `START_WINDOWS.cmd` (Python 3.11+). Linux/macOS: `python -m pip install -r requirements.txt`, затем `python launch.py`.

При обновлении сохраните прежний каталог `runtime` или значение `TARIFF_DATA_DIR`. Не заменяйте его пустым каталогом. Перезапустите сервер и обновите страницу: файлы интерфейса имеют версию `610`, `/health` должен возвращать `61.0`.

## Работа

1. В «Одном маршруте» выберите города. Сразу отображаются последние сохранённые цены. Нажмите «Обновить маршрут» для обращения к сайтам.
2. Над диаграммой выберите ₽ за отправку или ₽/кг. Ползунок ограничивает весовой диапазон от 0 до 20 тонн. Единицы таблицы задаются отдельно в «Настройках сравнения».
3. Нажмите на ячейку цены, чтобы ввести значение вручную. «Скачать Excel маршрута» создаёт отдельный XLSX с этим направлением и источниками.
4. Для документов откройте «Прайс-листы». Выберите компанию, один или несколько документов, распознайте и подтвердите цены. В «Одном маршруте» можно применить сохранённый документ к направлению.
5. В «Большой таблице» выберите 254 основных маршрута, все направления эталона или свой список. Сформируйте отчёт из сохранённых цен либо запустите онлайн-обновление. Загрузку можно остановить: полученные цены сохранятся.

Диаграмма в ₽/кг показывает расчётную стоимость отправки на килограмм с учётом минимальной платы. Это не всегда опубликованная ставка перевозчика. Большой Excel сохраняет прежнюю логику: малые веса и минимум — суммы; тяжёлые веса — подтверждённые ставки. Неизвестные ячейки остаются пустыми.

## Источники и сохранение

Цены поступают из текущих официальных источников, подтверждённых пользовательских файлов или явно введённых вручную значений. У каждой цены сохраняются источник и дата. Неудачная попытка обновления не стирает прежнюю цену. Сохранённые прайсы не удаляются через месяц; 30 минут — срок отметки свежести LIVE, а не срок хранения.

В каталоге `TARIFF_DATA_DIR` находятся оригиналы документов, SQLite библиотеки и заданий, ручные цены, сохранённые онлайн-результаты, кеши и журналы. Настройка только отдельной SQL-БД не сохранит оригиналы и JSON-файлы. На Render необходим постоянный диск и путь `TARIFF_DATA_DIR` внутри его точки монтирования. Например, при диске `/var/data`: `TARIFF_DATA_DIR=/var/data/tariff-app`. Эта версия не переносит данные в PostgreSQL и не изменяет настройки Render автоматически. До обновления/подключения диска сохраните текущие данные; для полного переноса скопируйте весь каталог данных при остановленной записи.

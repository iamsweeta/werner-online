# Тарифы — версия 63.0

Основная инструкция для вашего сайта: **[SETUP_RENDER_NEON.html](SETUP_RENDER_NEON.html)** (откройте в браузере) или [SETUP_RENDER_NEON.md](SETUP_RENDER_NEON.md).

В этой версии добавлено отдельное облачное хранение: PostgreSQL для цен/библиотеки/истории и S3-совместимое хранилище оригиналов. Render Free может оставаться сервером приложения. Перед обновлением скачайте резервную копию действующего сайта.

- Настройка Neon на компьютере: `SETUP_CLOUD_WINDOWS.cmd` или `python configure_neon.py`.
- Код приложения → GitHub; секреты из `render.env` → Render Environment; ZIP резервной копии → `/storage-guide` на новом сайте.
- `render.env` и прайсы в GitHub не загружать.
- Локальный запуск: `START_WINDOWS.cmd` или установка `requirements.txt` и `python launch.py`. Без `TARIFF_STORAGE=cloud` сохраняется локальный режим.
- Отчёт проверки: `QA_REPORT_V63_0.md`. Предыдущие отчёты описывают прежние версии.

## Рабочие разделы

«Один маршрут» — сравнение и отдельный Excel-файл. «Большая таблица» — сбор и экспорт всех выбранных направлений по структуре заказчика. «Прайс-листы» — общая библиотека документов. Подтверждённые цены не имеют срока удаления в приложении; дата и тип источника показаны отдельно.

До 50 кг и минимум — суммы отправки. В большой таблице для тяжёлых весов используются опубликованные ставки. На экране и в отдельном маршруте доступен переключатель суммы и расчётной цены за кг. Неизвестные цены остаются пустыми в Excel. Предустановленных рабочих цен нет.

Подробнее о форматах и обычной работе: `USER_GUIDE_V62.md` (раздел хранения заменён инструкцией версии 63). Старые `CHANGES_V62.md` и `QA_REPORT_V62_0.md` оставлены как история.

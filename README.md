# Тарифы перевозчиков · v51.0

Основной результат приложения — большая Excel-таблица в структуре эталона заказчика. Три раздела: **Большая таблица**, **Один маршрут**, **Прайс-листы**. Сравнение компаний, графики, минимумы, онлайн-загрузчики и прежний импорт для одного маршрута сохранены.

## Запуск

1. Закройте окно предыдущей версии и распакуйте **весь архив в новую папку**.
2. В Windows запустите **START_WINDOWS.cmd**. Нужен Python 3.11+ с командой `py`; первая установка зависимостей требует интернета.
3. Браузер откроется после проверки новой версии. По умолчанию используется порт 8423; если он занят другой установкой, выбирается свободный порт до 8443. Оставьте окно программы открытым.

Linux/macOS: `python -m pip install -r requirements.txt`, затем `python launch.py`.

## Большая таблица — основной сценарий

1. Откройте **«Большая таблица»**. По умолчанию выбраны **254 маршрута из Москвы/СПБ и все 17 подключённых компаний**, независимо от фильтров сравнения.
2. Нажмите **«Обновить онлайн и собрать таблицу»**. Для каждой компании и направления программа запросит источники и сохранит ответы. Есть прогресс, пауза после текущего маршрута, продолжение и повтор неудачных проверок.
3. Если цен не хватает, откройте **«Прайс-листы»** или нажмите **«Добавить прайс»** у компании в таблице заполненности.
4. Загрузите и подтвердите документы. Вернитесь в большую таблицу и нажмите **«Пересобрать Excel с прайсами»**. Недостающие онлайн-цены будут дополнены данными документов.
5. Скачайте готовый Excel. Программа показывает количество весовых цен из онлайн-ответов, из файлов и количество пропусков по каждой компании.

**Если интернет недоступен:** сначала добавьте документы, затем нажмите **«Собрать из текущих данных и прайсов»**. Этот режим не обращается к сайтам; использует подтверждённые документы и доступные онлайн-значения не старше 30 минут. Отчёт можно сформировать полностью из документов.

**Если нужно обновить цены на сайтах заново:** используйте **«Обновить онлайн и собрать таблицу»**. Пересборка готового отчёта меняет набор документов, но сохраняет онлайн-ответы предыдущего сбора с их исходными датами. Сохранённый XLSX — снимок данных; сам файл не запрашивает сайты и не обновляется при открытии в Excel.

После изменения прайсов старая ссылка на скачивание помечается как требующая пересборки. Это защищает от скачивания прежнего отчёта под видом обновлённого.

- **Основные:** Москва и Санкт-Петербург, по 127 назначений из каждого города — 254 направления. Список из 128 городов общий, собственный город исключён.
- **Все направления эталона:** 318 маршрутов, включая дополнительные отправления.
- В «Одном маршруте» переключатель **«Все города и другие отправления»** открывает расширенный каталог. Екатеринбург, Иркутск и остальные города сохранены.
- **Из выбранных городов:** выберите отправления и, при необходимости, назначения. Пустой выбор назначений означает все города справочника.
- **Все пары городов:** 54 056 направлений между 233 городами. Это длительный сбор, который может занять дни; доступность маршрута проверяется отдельно у каждого перевозчика.
- Более 400 маршрутов сохраняются частями по 200 в ZIP с перечнем направлений. После перезапуска программы продолжите незавершённый сбор.

## Один или несколько прайсов одной компании

1. Откройте **«Прайс-листы»** и выберите компанию.
2. Выберите **один или несколько PDF, XLS, XLSX, CSV** либо один ZIP с документами. Можно перетащить файлы в окно. До 30 документов, суммарно до 20 МБ; распакованные данные ограничены 120 МБ.
3. Город отправления определяется из документа. Укажите его вручную, если формат не позволяет распознать его однозначно или нужно ограничить большой прайс. При известной дате укажите дату тарифов.
4. Нажмите **«Распознать маршруты и цены»**. Программа объединит разные маршруты и непересекающиеся весовые строки. Совпадающие цены не дублируются.
5. Если у одного маршрута и веса есть **разные цены**, выберите нужную редакцию по имени файла, сумме и дате. Без выбора всех конфликтующих цен сохранение невозможно.
6. Посмотрите распознанные направления и цены, проверьте оригиналы и актуальность. Отметьте подтверждение и нажмите **«Сохранить прайс-лист»**. До этого шага рабочие цены не меняются.
7. Соберите или пересоберите большую таблицу.

Один прайс может заполнить много маршрутов. Направления «А → Б» и «Б → А» не смешиваются. Данные разных компаний не объединяются. Сохранение всей загрузки выполняется одной операцией; оригинальные файлы доступны для проверки. При выборе нескольких файлов оригиналы сохраняются вместе в ZIP; у каждой цены указан конкретный документ внутри архива.

**Части одного прайса загружайте вместе.** Новая загрузка заменяет прежний прайс компании для затронутых маршрутов целиком. Отсутствующие в новой редакции веса не подтягиваются из старого документа. Остальные маршруты сохраняются. В разделе документов можно отключить файл; после изменения пересоберите отчёт.

Ранее загруженные прайсы одного маршрута тоже используются в большой таблице. Управлять ими можно в разделе **«Один маршрут» → «Прайс для маршрута»**.

### Если формат не распознан

Нажмите **«XLSX · диапазоны и ставки»**. Компания и маршруты уже подготовлены, цены пустые. Без выбранного отправления шаблон содержит 254 основных маршрута; с выбранным городом — направления из него. Исправьте границы под исходный прайс, внесите подтверждённые тарифы и загрузите файл обратно.

Новый шаблон Excel/CSV содержит колонки:

`Компания;Откуда;Куда;Вес от, кг;Вес до, кг;Тариф;Единица;Минимум, руб`

- **руб** — фиксированная стоимость отправки; **руб/кг** — опубликованная ставка. Единицы выбираются по оригиналу.
- Нижняя граница исключается, верхняя включается. Например, 0–5 и 5–20 не перекрываются. Одинаковые границы задают один контрольный вес. Для открытого верха напишите `∞`.
- Если в оригинале 0–5 кг = 196 руб, достаточно одной строки: приложение заполнит 0–1, 1–3, 3–5 по 196 руб. Это пример логики, а не актуальная цена.
- Минимум заполняйте только для ставки руб/кг и только если он явно указан в прайсе. Для фиксированной суммы эта колонка пустая.
- Пустые тарифы пропускаются; интервалы с заполненными тарифами не должны перекрываться. Удалите ненужные строки.
- Контрольный вес сравнения — верхняя граница его строки. Если исходный тариф меняется внутри общего диапазона, приложение не утверждает, что весь диапазон имеет одну цену: исходные границы сохраняются при импорте.

Прежний шаблон **«Контрольные веса»** сохранён: `Компания;Откуда;Куда;Вес, кг;Цена, руб`. Это сумма для конкретного веса. Строка 5 кг не означает автоматически тариф для всех меньших весов; строка 100 кг с итогом отправки не подтверждает ставку руб/кг. Для полного тарифного Excel используйте исходный распознаваемый прайс или шаблон диапазонов.

| Компания | Нативный документ |
|---|---|
| Werner | Исходный XLS/XLSX с тремя фиксированными и семью весовыми колонками, явным отправлением и брендом. Изменённый макет отклоняется. |
| ДЛ | Текстовый PDF, первая таблица «Тарифы на межтерминальную перевозку из …». Проверяются отправление, назначение и границы диапазонов. |
| Возовоз | XLS/XLSX, лист «Тарифы межтерм.перевозок» обычной перевозки; также ZIP с документами. |
| КИТ, Новая Линия | Текстовый PDF исходящих междугородних тарифов. |
| ПЭК | Сводный XLSX с листом «Перевозка» и колонками отправления/назначения. |
| Фортуна, ЭкспедицияПлюс | Основной XLSX, исходящий раздел листа города. |
| Рейл Континент | XLSX исходящих автомобильных тарифов в рублях. |

Общий PDF должен содержать строки `Компания: …`, `Откуда: …`, `Куда: …` и таблицу `Вес, кг | Цена, руб`. Для интервалов поддерживается заголовок `Вес от, кг | Вес до, кг | Тариф | Единица | Минимум, руб` с явными единицами в каждой строке. Произвольный макет, скан без текстового слоя, DOC/DOCX автоматически не поддерживаются. Для них используйте подготовленный XLSX-шаблон; OCR не включён.

Подсказка выбранной компании содержит официальный адрес и инструкции из таблицы заказчика. Сводка источников — `CUSTOMER_SOURCES.md`.

## Светлая и тёмная темы

Лаунчер открывает приложение на белом фоне. Вверху две явные кнопки: «Светлая» и «Тёмная». Выбор сохраняется для перезагрузки страницы; следующий запуск через START_WINDOWS снова открывает светлую тему. Светлые страницы, меню, карточки, таблицы и диалоги имеют фон #FFFFFF.

## Отдельный маршрут

Два режима интерфейса: **«За отправку · ₽»** и **«За килограмм · ₽/кг»**. Второй делит сумму отправки на контрольный вес; это расчётная стоимость, которая может отличаться от опубликованной ставки из-за минимальной платы. МИН всегда показывается в рублях. Смешанного режима интерфейса нет. Светлая тема использует белые поверхности, тёмная — почти чёрные; цвета графиков адаптируются.

Откройте **«Один маршрут»**, выберите города и компании. Здесь работают прежние сравнение, все весовые диапазоны, графики, минимальная отправка, настройки API и повтор загрузки источника.

**«Скачать Excel маршрута»** создаёт отдельный файл XLSX с названием выбранного направления. В нём только таблица этого маршрута и лист источников; служебные листы большой книги не добавляются. Выгружаются выбранные компании, все весовые диапазоны и текущий режим экрана (₽ либо расчётные ₽/кг; МИН всегда ₽). Пустые цены остаются пустыми. Общая выгрузка в структуре эталона запускается отдельно в разделе большой таблицы.

В сравнении подтверждённые импортированные строки имеют приоритет перед онлайн-строками до отключения файла — это сохранённое поведение прежней версии. Для большой таблицы приоритет обратный: подтверждённый сопоставимый онлайн-тариф этого сбора, затем файл при его отсутствии. Если калькулятор дал только сумму для большого веса, файл со ставкой руб/кг заполняет этот пробел. Источник виден у каждой цены.

## Структура Excel и достоверность

Встроенные архивные цены и таблицы цен в коде отключены и удалены из рабочих данных. Даже при обновлении старой установки файлы `data/v42` не читаются как цены. Рабочие источники — ответы сайтов/API и подтверждённые документы пользователя. Тестовые файлы в `tests/fixtures` не подключены к приложению. Сохранённые прежние онлайн-ответы пользователя помечаются LAST GOOD и видны только при соответствующем фильтре.

Эталон используется только как структура: листы, колонки, рабочие связи и графики. Цены из примера заказчика не копируются. Общий отчёт содержит 43 листа, включая дополнительные «Источники», «Сбор» и Байкал Сервис.

- D:L — стоимость малого отправления, ₽.
- M / МИН — минимальная подтверждённая стоимость отправления компании на этом маршруте, ₽. Нужен опубликованный минимум или первый диапазон 0–1 кг; один тяжёлый тариф минимум не подтверждает. Например, 600 либо 3090, без деления на вес.
- N:AF — **опубликованная ставка** от 100 кг, ₽/кг. Она не вычисляется делением итоговой суммы на вес. Например, ставка 10 руб/кг и минимальная плата 1500 руб дают 1500 руб за 100 кг, но в тарифном Excel остаётся 10 руб/кг.
- Если известна только сумма расчёта, тяжёлая тарифная ячейка остаётся **пустой**. Сумма и причина доступны на листе «Источники».
- В Excel эталона до 50 кг и МИН единица — рубли за отправку. Переключение режима на экране не меняет правила Excel эталона.
- **Сбор** — объём обработки, источники числовых ячеек и пропуски.
- **Источники** — компания, маршрут, время получения, исходный файл/URL, дата документа, страница/строка, контрольная сумма, опубликованная ставка, минимальная плата и ошибка источника.

Подключены **17 компаний и весовые тарифы**. «Грузопоток» исключён по требованию заказчика, в том числе из активного списка и выгрузки. Дополнительные компании, исторические листы и объёмные колонки эталона сохраняются в структуре, но их ценовые ячейки остаются пустыми. Не выбранная компания, отсутствующая ставка и исключённый фильтром источник также дают пустую ячейку. Причины — на листах «Источники» и «Сбор». Нулевые тарифы не подставляются.

LIVE в сравнении — подтверждённая текущей онлайн-попыткой цена не старше 30 минут. Документ пользователя — отдельно подтверждённый источник; дата загрузки не доказывает актуальность тарифов. Будущие распознанные даты отклоняются; при неизвестной или старой дате показывается предупреждение.

Большой сбор сохраняет цены на время ответа каждого источника. Это не одновременный LIVE всех сайтов. При недоступности сайта документ позволяет заполнить известные цены, но программа не может гарантировать числовые тарифы там, где их нет ни в источниках, ни в документах.

Сравниваются базовые весовые тарифы. Объём, габариты, адресные услуги, страховка, скидки и надбавки могут менять стоимость. Цена «от» не размножается на все веса.

## Хранение и резервная копия

Подтверждённые документы хранятся бессрочно в папке текущей установки: оригиналы — `runtime/imports/files`, распознанные цены — SQLite и JSON в `runtime/imports`. «Отключить» прекращает использование прайса, но сохраняет оригинал и историю. Предпросмотр действителен 30 минут; просроченные временные файлы очищаются при обращении к загрузкам и открытии приложения. Облачного хранения нет.

Кнопка **«Скачать резервную копию прайсов»** сохраняет оригиналы и согласованную копию распознанных данных. Перенесите архив на другой диск; восстановление описано в его `RESTORE.txt`. Если распаковать новую версию в другую папку, документы автоматически не переносятся. Удаление старой папки программы удалит и её локальные данные.

Рабочий приоритет: подтверждённая онлайн-цена, затем прайс пользователя для пропусков. Для тарифного Excel пропуском считается также отсутствие опубликованной ставки за кг, когда онлайн-калькулятор вернул только итог отправки. Источник каждого значения указан отдельно. Старые онлайн-цены сохраняются, но после 30 минут не считаются LIVE. В новом общем сборе документ может повторно использоваться до 5 минут с исходным временем скачивания; каждый маршрут проверяется заново. Кеш не переносится в следующий сбор.

Условия НДС по возможности извлекаются из исходного документа и выводятся в источниках. Налоговая ставка не предполагается и цены автоматически не пересчитываются.

Полный ответ об источниках, хранении, эталоне и известных ограничениях — **AUDIT_V51.md**. Проверены 17 компаний на одном маршруте: 9 полных весовых сеток, 3 частичных результата, 5 неподтверждённых загрузок. Это не гарантия доступности всех компаний и маршрутов.

## Перенос, диагностика и проверки

При остановленной программе перенесите **всю папку `runtime/imports`** из предыдущей установки: там оригиналы и привязки прайсов. Для переноса онлайн-кеша и заданий можно перенести всю `runtime`; API-настройки тоже останутся в ней. После переноса старые выгрузки автоматически требуют пересборки: старые текстовые заглушки заменяются пустыми ячейками и применяется оформление эталона. Незавершённые маршруты и документы сохраняются, «Грузопоток» исключается из старых заданий.

`RESET_LIVE_V42.cmd` сбрасывает онлайн-кеш, сохраняя документы и настройки. Диагностика выбранного маршрута доступна в его разделе; настроенные API-ключи скрываются.

Проверки: установите `requirements-dev.txt`, выполните `python -m unittest discover -s tests`. Интерфейс: `jsdom@26.1.0` и `node tests/ui.test.cjs`, `node tests/import_ui.test.cjs`, `node tests/bulk_ui.test.cjs`, `node tests/workspace_ui.test.cjs`, `node tests/customer_ui.test.cjs`.

В этой сборке непосредственно скачаны XLSX Werner для Москвы и Санкт-Петербурга и общий XLSX Фортуны по ссылке с её официальной страницы. По каждому Werner разобрано 127 направлений × 28 контрольных весов. Используется текущий адрес файла на сайте, а не встроенный прайс; дата внутри документов Werner — 10.08.2026.

У Фортуны обработано 438 исходящих автомобильных направлений из 19 городов, на каждом 28 весов и минимум. Остальные 50 строк направлений содержат договорные цены или только отдельную железнодорожную перевозку. Они не превращаются в числовые автотарифы. Оформленные пустые столбцы больше не блокируют всю книгу, соседняя железнодорожная строка не заменяет автотариф.

Это проверка этих источников в указанную дату, а не обещание доступности всех перевозчиков всегда. При недоступности сайта загрузите доступный вам документ. История проверок других перевозчиков сохранена отдельно в docs; она не подтверждает их доступность сегодня.

# Краткая инструкция · 61.0

## Один маршрут

Выберите отправление и назначение. Сохранённые цены доступны сразу. «Обновить маршрут» запускает загрузку с сайтов. При ошибке сохраняется предыдущая цена с датой и статусом источника.

«Цена на диаграмме» переключает всю диаграмму между ₽ за отправку и ₽/кг. Вторая величина рассчитывается как сумма отправки / контрольный вес и включает минимальную плату. Переключатель не меняет цену в базе и не меняет Excel. «Масштаб графика» и два ползунка ограничивают вес. На телефоне график целиком помещается по ширине, все точки остаются доступными; подписи веса показаны реже.

Для изменения ячейки нажмите на неё, введите цену и единицу, сохраните. «Скачать Excel маршрута» создаёт самостоятельный файл с листами «Маршрут» и «Источники».

## Документы и большая таблица

«Прайс-листы» — общая библиотека документов. Загрузите документы одной компании, дождитесь распознавания, проверьте цены и подтвердите. Можно хранить несколько версий. Для конкретного направления раскройте «Прайсы для этого маршрута», выберите документ и примените его. После сохранения выводится подтверждение. Импорт через окно одного маршрута сохраняет только выбранное направление; для всех направлений документа используйте библиотеку.

В «Большой таблице» основной список содержит 254 направления. «Собрать Excel из сохранённых цен» использует общие данные без обращения к сайтам. «Обновить цены онлайн» проверяет выбранный список. «Остановить загрузку» прекращает запуск новых проверок, уже начатые завершаются и сохраняются. Продолжение доступно из истории.

После изменения цен пересоберите Excel. Скачанный файл автоматически не обновляется. Если подтверждённой цены никогда не было, ячейка остаётся пустой.

## ПЭК и БСК

ПЭК использует свежую сводную XLSX-книгу. БСК — таблицу в официальной форме выбора городов. На момент проверки БСК публиковал Москва → Санкт-Петербург как составной маршрут; его пометка сохранена в источнике. Это опубликованные перевозчиком значения, а не гарантия коммерческого расчёта с учётом всех параметров груза. Проверяйте необычные ставки по ссылке на источник.

Ошибку обновления можно повторить из «Статистики и состояния загрузки» либо из подробностей выбранного веса. При блокировке сайта загрузите официальный прайс в библиотеку. На Render сохранность между перезапусками требует постоянного диска; подробности в README.

# Обновление до 63.2: загрузка и сохранение вместе

Версия исправляет задержки, которые появились при переносе данных из локальных
файлов в облачную базу. Базу и файловое хранилище пересоздавать не нужно.

## Установка на существующий Render

1. Если на сайте есть важные данные и он отвечает, скачайте резервную копию.
2. Распакуйте архив. Замените файлы в GitHub **содержимым** папки `TARIFF_APP_V63_2`:
   `app`, `static`, `data` и остальные файлы должны лежать в корне репозитория
   рядом с `requirements.txt`. Пользовательские файлы и секреты не загружайте.
3. В Render → ваш сервис → Environment оставьте текущие значения `DATABASE_URL`
   и всех `S3_…`. Режимы должны быть:

   ```env
   TARIFF_STORAGE=cloud
   APP_AUTH_MODE=public
   ```

4. Render → Manual Deploy → **Deploy latest commit**. Дождитесь успешного запуска
   именно нового коммита. При изменении переменных используйте
   **Save, rebuild, and deploy**.
5. Откройте `/health` своего сайта. Ожидаются `version: "63.2"`,
   `access_mode: "public"`, `storage_mode: "cloud"`.
6. Обновите главную страницу через Ctrl+F5. Выберите маршрут: подтверждённые цены
   должны появиться из прежней базы. Новую онлайн-загрузку запускайте кнопкой
   «Обновить маршрут» только когда нужно обновить цены.
7. Проверьте базу и файловое хранилище на `/storage-guide`. Для уже подключённого
   облака повторный импорт резервной копии и запуск configure_neon.py не нужны.

Если сбор был прерван перезапуском, ранее сохранённые цены остаются. Продолжить
обновление источников можно через кнопки загрузки. Скорость ответа самих сайтов
перевозчиков, распознавания сканов и запуск после сна Render Free могут отличаться
от скорости показа уже сохранённых цен.

## Что исправлено

- Для таблицы и диаграммы считывается один согласованный набор данных маршрута.
- Вложенные обращения используют одно соединение с базой, а чтение цен не требует
  общей блокировки записи.
- Повторные одинаковые запросы интерфейса объединяются; при старте нет трёх
  параллельных пересчётов одного маршрута.
- Прогресс онлайн-загрузки не перезагружает неизменившийся список городов.
- Отправка онлайн-оригинала в S3 выполняется до блокировки записи цен. Ссылка на
  оригинал и новая цена публикуются только после успешного сохранения.
- Запись прогресса в облако не удерживает блокировку API статуса.
- Выгрузка большой таблицы читает документы без общей блокировки всех цен.
- Служебный `/health` отвечает независимо от очереди синхронных обработчиков.

Формат Excel, приоритет ручных и загруженных цен и бессрочное хранение подтверждённых
данных сохранены. Неполученные или неподтверждённые цены не заполняются догадками.

Отчёт проверок — `QA_REPORT_V63_2.md`. Публичный режим остаётся общим рабочим
пространством: посетители могут просматривать и изменять цены и файлы.

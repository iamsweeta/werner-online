# Изменения 56.0

- OCR одного маршрута читает столбец городов и только найденную строку вместо всех цен документа.
- Точные названия, переносы строк, повторяющиеся города и направление проверяются. Цена не угадывается; два чтения должны совпасть.
- Поиск повторного заголовка на следующих страницах начинается с меньшей области и расширяется при необходимости.
- Для общей библиотеки сохранён полный OCR. Частичный результат не подменяет полный индекс документа в кэше.
- Видны этап, страница, общее время; после 30 секунд на этапе — пояснение. Этап более 120 секунд завершается ошибкой с принудительной остановкой OCR-процесса.
- Проверка зависшего OCR работает и без слушателя прогресса. Обычный heartbeat сервера не выдаётся за продвижение распознавания.
- Фоновые задания, восстановление окна, явное подтверждение, общая библиотека и экспорт сохранены. Номер задания в браузере сохраняет совместимость с 55.0.

Обновление: перенесите runtime или сохраните TARIFF_DATA_DIR, замените приложение, перезапустите сервер, обновите страницу. Незавершённый скан загрузите заново. Работающий сервер пользователя этой поставкой автоматически не обновляется.

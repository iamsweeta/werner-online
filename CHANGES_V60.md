# Изменения 60.0

- «Один маршрут» открывается первым при каждом входе, включая пользователей с ранее сохранённой вкладкой «Большая таблица». Порядок меню: маршрут → большая таблица → прайс-листы. Последний выбранный маршрут и настройки единиц сохранены.
- Основной экран: выбор направления, обновление/импорт/Excel, диаграмма и полная таблица цен. Статистика, источники, выбор сохранённого документа, фильтры и отдельное сравнение на один вес свёрнуты по умолчанию.
- Убраны повторяющиеся инструкции, крупные вводные блоки и дублирующий тип тарифа в каждой строке экранной таблицы. Условия единиц, даты/источники и предупреждения OCR доступны; числовые данные и Excel не изменены.
- Заполненность большой книги, ответы компаний, подробные счётчики и хранение документов раскрываются по необходимости. Текущий прогресс загрузки остаётся видимым.
- Выбор компаний сразу обновляет сравнение. Снятие всех компаний очищает показанные результаты и отменяет незавершённый запрос сравнения.
- Кнопка «Применить цены из файла»: состояние «Применяю…», затем «✓ Цены применены». Подтверждение с именем файла и количеством цен — рядом с кнопкой, в нижней панели окна. После сохранения доступна кнопка «Готово»; повторное применение блокируется.
- Ошибка применения показывается у кнопки. Ошибка обновления экрана после успешного сохранения не отменяет подтверждение сохранённых данных.
- Сохранены светлая/тёмная темы, мобильные стили, ручные цены, обе Excel-выгрузки, долговременная библиотека, Возовоз, фоновые задания и ускорение OCR предыдущей версии.

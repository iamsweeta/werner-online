# Обновление существующего сайта до 63.1

Эта версия позволяет открыть сайт без пароля, сохраняя цены и документы в Neon.
Публичный режим — общее рабочее пространство: любой посетитель может читать
таблицы, скачивать документы, загружать прайсы и менять цены.

## Что сделать

1. Если на сайте уже есть нужные данные, скачайте резервную копию в разделе
   «Прайс-листы» или «Хранилище и перенос данных» до обновления.
2. Распакуйте архив. Загрузите **содержимое** папки `TARIFF_APP_V63_1` в корень
   репозитория GitHub, который подключён к Render. Папки `app`, `static`, `data`
   должны оказаться рядом с `requirements.txt`. Замените существующие файлы.
   `render.env`, `.env` с секретами и пользовательские прайсы в GitHub не загружайте.
3. Render → ваш сервис **werner-online** → **Environment** → **Environment Variables**.
   Добавьте одну переменную:

   | Key | Value |
   | --- | --- |
   | `APP_AUTH_MODE` | `public` |

4. `TARIFF_STORAGE` должен оставаться `cloud`. Существующие `DATABASE_URL` и все
   `S3_…` сохраните. `APP_PASSWORD` можно оставить: в публичном режиме он игнорируется.
   Программу настройки Neon повторно запускать не нужно; новый проект, ветку или бакет
   создавать не нужно.
5. Выберите **Save, rebuild, and deploy**. Дождитесь успешного запуска нового коммита.
   Если код ещё не попал в этот запуск, выполните **Manual Deploy → Deploy latest commit**.
6. Откройте `/health` на своём сайте. Ожидаются:

   ```json
   {"version":"63.1","access_mode":"public","storage_mode":"cloud"}
   ```

   В ответе будут и другие поля — это нормально. `storage_mode` показывает выбранный
   режим; отдельная проверка ниже проверяет подключение к базе и файловому хранилищу.
7. Обновите главную страницу через **Ctrl+F5**. Должны появиться города и компании
   без окна входа. Откройте «Хранилище и перенос данных» (`/storage-guide`) и нажмите
   кнопку проверки базы и файлового хранилища. Проверка должна завершиться успешно.
8. Если требуется перенос старой резервной копии, выполните его на странице
   `/storage-guide` до добавления новых данных: импорт рассчитан на пустое облачное
   хранилище. Существующую заполненную базу очищать для обновления не нужно.

## Что исправлено

- Явный режим `APP_AUTH_MODE=public` совместим с PostgreSQL и закрытым S3-бакетом.
  Закрытый бакет не становится публичным: документы выдаёт само приложение.
- Списки городов, компаний и диапазонов больше не ждут чтения тарифов из базы.
  Подробности источников подгружаются при раскрытии соответствующего раздела.
- Ошибки доступа и загрузки остаются видимыми с кнопкой повторной попытки.
- Тайм-аут списка больше не воспринимается как обычная отмена переключения маршрута.
  Ранее это могло оставить интерфейс с пустыми списками без понятного сообщения.
- Диагностика `/health` показывает фактические режимы доступа и хранения.
- Формулы тарифов, структура Excel и сохранённые цены этой версией не изменяются.

Для возврата к закрытому доступу задайте `APP_AUTH_MODE=password` и `APP_PASSWORD`
длиной минимум 12 символов. Логин — `APP_USERNAME`, по умолчанию `manager`.

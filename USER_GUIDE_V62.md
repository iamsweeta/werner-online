# Работа с тарифами 62.0

## Один маршрут

Выберите «Откуда» и «Куда». Последние сохранённые цены отображаются сразу. Переключатель «Цены в таблице и Excel маршрута» виден рядом с маршрутом. Для диаграммы есть отдельный видимый переключатель. ₽/кг в этих двух режимах — сумма отправки, делённая на контрольный вес, с учётом минимальной платы. Это может отличаться от опубликованной ставки.

Нажмите на цену или пустую ячейку для ручного ввода. Значение сохранится для конкретной компании, направления и диапазона. «Скачать Excel маршрута» создаёт отдельный файл выбранного направления.

## Большая таблица

«Основные · 254» — Москва и Санкт-Петербург, по 127 направлений. Можно выбрать 318 направлений эталона или собственный список. «Из сохранённых данных» формирует отчёт без новых запросов к перевозчикам. Онлайн-обновление собирает новые ответы и сохраняет прежние значения, если свежую цену получить не удалось.

Остановка прекращает запуск новых проверок. Уже выполняющиеся проверки сохраняют результаты. После паузы можно скачать все запланированные направления с доступными ценами или продолжить. История показывает выбранный сбор без самопроизвольного переключения на другой.

После изменения цены или источника старый Excel помечается устаревшим: нажмите «Создать Excel». В основной книге до 50 кг и минимум — ₽, тяжёлые веса — опубликованные ₽/кг. Если сайт дал только итоговую сумму, а подтверждённый файл содержит ставку, ставка может заполнить пропуск. Источник указан в книге. Неизвестные ячейки остаются пустыми. Сетка объёмов и неподключённые исторические листы сохраняют структуру без вымышленных чисел.

## Прайс-листы

Выберите компанию, один или несколько файлов, распознайте, проверьте результат и подтвердите. Библиотека общая для большой таблицы и отдельного маршрута. Для выбранного направления можно явно применить нужный документ. После применения появляется подтверждение.

Файлы не удаляются по истечении месяца. «Отключить» исключает документ из расчётов, сохраняя оригинал. Резервная копия включает документы, ручные и онлайн-цены. На Render хранение между перезапусками требует Persistent Disk: см. `RENDER_SETUP.md` и ссылку в предупреждении приложения.

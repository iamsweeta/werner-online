# Проверки 58.0

Статус: функциональные проверки и запуск из распакованного ZIP пройдены.

- 29 проверок общего сбора, файлов и сохранения последних успешных цен: пройдены.
- 5 новых проверок: полноценный Excel на 254 направления из накопленной базы и документов; остановка внутри маршрута; продолжение только оставшихся компаний; API остановки и история; сохранённые цены не помечаются новой сетевой проверкой.
- 42 проверки OCR, кэша, векторных контуров, растрового скана, фоновых заданий и импорта: пройдены.
- 11 клиентских наборов: пройдены, включая границы ползунков, охват до 20 т, график малых отправок в ₽, скрытые дополнительные действия и кнопку остановки.
- 18 проверок аудита/релиза: пройдены. Проверены очищенный шаблон и отсутствие установленных рабочих цен.
- Запуск из нового распакованного архива через HTTP: версия 58.0, 17 компаний, 127 назначений для каждого основного отправления, отдельный XLSX маршрута. В чистой установке тарифные ячейки пустые.
- Белый фон и тёмная тема, клиентские сценарии и правила адаптивной вёрстки проверены автоматически. Скриншот новой версии в реальном мобильном браузере не получен: исполняемый браузер в среде недоступен; проверку на устройствах клиента это не заменяет.
- Реальный dsjf.pdf через HTTP: один маршрут 28,554 с; весь документ 49,364 с; после перезапуска повторный полный разбор 0,715 с и маршрут 0,355 с. 220 маршрутов / 6160 значений совпали с контрольным разбором. Оригинал сохранён побайтно, отдельный Excel маршрута проверен. Максимальный запрос статуса 0,373 с при таймауте HTTP 1 с.

Тестовые значения в автотестах синтетические, рабочими прайсами приложения не являются. Исходный PDF клиента в архив приложения не включён. Замеры зависят от мощности сервера и вида PDF; для растровых сканов ускорение по контурам неприменимо.

Новые сетевые проверки всех компаний в этой версии не выполнялись. Доступность сайтов и достоверность загруженного клиентом документа не гарантируются. Для неизвестных сканированных макетов остаётся XLSX/CSV-шаблон.
